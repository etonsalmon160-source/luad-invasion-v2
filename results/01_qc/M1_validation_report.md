## 4. `P7_LUAD`：根因定位与修复（v2 → v3）

**现象**：唯一双体率 = 0 的样本（10,164 核），`scDblFinder` 报 `Threshold found: 1`。

**排查过程**：
1. 该样本**质量正常**（median nCount 1,478 / nFeature 1,084，**高于**队列中位 1,268/…）；
2. 同患者另两样本正常（`P7_Normal` 12.05%、`P7_LUAD1` 12.37%）→ **非生物学原因**；
3. 分数分布：该样本**全部为 0**（非"分离度差"）；
4. 日志显示迭代**塌缩**：`iter=0 排除 1515 → iter=1 排除 1 → iter=2 排除 2`。

**根因**：`scDblFinder` 默认打分器 **`xgb` 分类器在该样本上训练塌缩** → 全部分数=0 → 阈值→0.999。

**验证与修复**：改用 `score="weighted"` → 阈值 0.325 → **1,158 双体（11.69%）**，与同患者样本一致。

**处置**：
- 对该样本按 `cell_barcode` **精确回填**（脚本 `01_qc/09_fix_p7_weighted.R`）；
- **主脚本已加入自动 fallback**（xgb 判 0 → 自动改用 weighted 并打印提示），杜绝此类静默失败。

> **结果**：全队列**不再有未解释的异常样本**（双体率最低 4.43%）。

## 5. 参数与出处

| 参数 | 值 | 出处 |
| :--- | :--- | :--- |
| QC 阈值 | `nCount`/`nFeature` **逐样本 MAD 离群**（`scuttle::isOutlier`, nmads=3, log1p, 双尾） | scater/scuttle 标准（McCarthy 2017）——**公认** |
| `pct_mt` | **< 5%** | ⚠️ **本项目约定**（核；全队列 99% 分位 6.44） |
| 双体 | `scDblFinder(dbr=NULL, dbr.sd=NULL, aggregateFeatures=FALSE, score="xgb")` 逐样本；**失败自动回退 `weighted`** | Bioconductor 参考——**公认** |
| 确定性 | `set.seed(1)` + `SerialParam()` | 复现要求 |

> **为何不照搬 scRNA 阈值**：本数据 median nCount = 1,516、median pct_mt = 0.6%（细胞核特征）。
> 整细胞约定（`nCount≥1,000`）会**砍掉约 30% 的核** → 故**先测后定**。

## 6. 方法学诚实声明：第二方法交叉验证**在本环境不可行**

| 方法 | 结果 | 证据 |
| :--- | :--- | :--- |
| **scrublet**（Py） | ❌ **不适用** | 稀疏核下**可检测双体比例仅 ~0.5%**；max score 0.495 < 自动阈值 0.556 → 判 0 双体（全 75 样本一致） |
| **DoubletFinder**（R） | ❌ **不兼容** | 2.0.3 内部用 `seu@data`/`seu@raw.data`（**Seurat 2/3 API**）；新版仅支持 Seurat 5。本机 Seurat **4.3.0** → 两者均套不上 |

**故以 `scDblFinder` 为单一主方法**，并以**两项独立的内部验证**替代：

**验证 A · 计数特征**（真双体 = 两细胞并入一滴 → 计数应约 2×）
> **75/75 样本**双体 nCount 比 **中位 2.39**（范围 1.85–4.12）、nFeature 比中位 2.05；
> 双体率 vs 样本细胞数 **r=0.921**（符合 10x 载量关系）。

**验证 B · 跨谱系共表达**（**独立于 scDblFinder**；真双体应同时表达互斥谱系标记）
> 取 上皮 `EPCAM` × 免疫 `PTPRC`（互斥谱系）：
> **doublet 双阳性率 中位 3.15% vs singlet 0.49%**；**72/75 样本（96%）doublet 更高**；**倍数比中位 7.2×**。
> → 判定的细胞**确实富集"跨谱系"共表达**，即真双体特征；**排除"仅把高计数单细胞误判为双体"**。

> 注：验证 B 的绝对水平低（3.15%）系因**多数双体为同谱系**（如两个上皮细胞）不表现为跨谱系；
> 7.2× 是小基数上的强富集。两项验证共同支持：**判定方向正确、非噪声**。

**关于 15.48% 的诚实说明**：该值**按细胞数加权**，被大样本拉高（P24_LUAD 58k 细胞 → 29%）。
"典型样本"率为**中位 10.6%**。scDblFinder 的 `dbr=NULL` **按细胞数推算**率 → 报告时应**逐样本呈现**
并注明为**模型估计**，而非独立测量。

## 7. 已修复的真实缺陷（v1/v2 → v3）

| # | 缺陷 | 根因 | 修复 |
| :--- | :--- | :--- | :--- |
| 1 | `cell_barcode` 全为 `"0\|<样本>"` | `fread` 因首行字段数≠数据行而 **autostart 跳过条码行** | 单独读条码行 + `skip=1` + `stopifnot` 断言 |
| 2 | 修 #1 后数据行被多丢一行 | `dt[-1,-1]` 重复丢行 | 改 `dt[,-1]` |
| 3 | `P7_LUAD` 判 0 双体 | **xgb 分类器塌缩**（非生物学） | `score="weighted"` + 主脚本自动 fallback |

## 9. 下游注意事项

1. **双体剔除比例对结果有一定影响**（与固定 10% 重合约 62.3%）→ **必须在关键分析处做"剔/不剔双体"敏感性**（最强防线）；
2. 全队列无未解释异常样本；剩余疑点仅为**双体率整体偏高（15.48%）**，其来源已解释（大样本 + 按细胞数自估）；
3. 空间数据（GSE307534）的 spot QC **不在此范围**（属空间前处理）。
