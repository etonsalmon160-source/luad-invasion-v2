# 上皮子集前置 —— 预注册（2026-09-16，**执行前**登记）

> 法则 3.1：参数必须显式常量化并登记。法则 3.2：阈值一经确定不得事后调整。
> 本文件在任何上皮臂运行**之前**写成；下面的规则、守卫和判读标准此后不得改动，
> 若要改，必须另开一版并注明改了什么、为什么改、改之前跑出了什么。

## 1. 要回答的唯一问题

**把输入从"一个样本的全部细胞"改成"只留上皮细胞"，能不能消除 2026-09-16 发现的那个失效模式？**

失效模式的实测证据（`GP1_report.md` §9）：Normal 样本判出 40.7%–59.0% "非整倍体"，
且判决随地板/阈值在两个极点之间翻转。根因假设：**CopyKAT 的设计前提是输入同一谱系**，
喂入混合谱系时，层次聚类的第一刀切的是细胞类型。

支撑该假设的直接实测（`ab_A_*` 三样本，全细胞 + 地板 840 + 0.05/0.10）：

| 样本 | 判"非整倍体"组 | 判"二倍体"组 |
| :--- | :--- | :--- |
| P13_Normal | EPCAM 0.63 (34%) | EPCAM 0.05 (3%) |
| P11_Normal | EPCAM 0.67 (36%)、PTPRC **0.00 (0%)**、LYZ 0.05 | LYZ 0.63 (18%)、DCN 1.02 (34%) |
| P14_Normal | EPCAM 0.79 (40%)、LYZ 1.48 (41%) | PECAM1 1.10、DCN 1.15 |

即：**判决完全由谱系构成决定**，"非整倍体比例"实际在量上皮细胞占比。

## 2. 这是**输入对象**的修正，不是参数调整

地板（840）、`LOW.DR`（0.05）、`UP.DR`（0.10）、`min.gene.per.cell`（200）、
`ngene.chr`（5）、`win.size`（25）、`KS.cut`（0.1）、`n.cores`（1）**全部不变**。
对照设计只有**一个**变量：传入矩阵的细胞集合。子集施加在地板**之后**，
使"全细胞 vs 仅上皮"除该变量外逐位一致。

## 3. 上皮判据（逐字照抄 `00_common.R::epi_call()`）

marker 来源：`docs/scientific_rigor_and_audit.md` 法则 2 表，逐行照抄，不增删。
实测本数据集 75 个 h5ad 的基因表（P13_Normal 为样本）**37 个 marker 全部存活**（37/37）：

```
epithelial  EPCAM,KRT7,KRT19,NKX2-1,SFTPC,SFTPB,AGER                7/7
tnk         CD3D,CD3E,CD4,CD8A,GZMB,PRF1,NKG7                       7/7
bplasma     CD19,MS4A1,CD79A,SDC1,IGHG1                             5/5
myeloid     CD68,CD163,C1QA,C1QB,C1QC,SPP1,MARCO                    7/7
fibroblast  COL1A1,COL1A2,ACTA2,PDGFRB,FAP,CXCL12                   6/6
endothelial PECAM1,VWF,CDH5,EGFL7,KDR                               5/5
```

- 归一化：`log1p(count / lib * 1e4)`，lib = 该细胞全基因计数和；**样本内**逐细胞算。
- 谱系 score = 该谱系存活 marker 的**行均值**（细胞 × 6）。
- **规则 `argmax`**：细胞的 score 最大谱系 = 上皮 **且** 与最高分差 ≤ 1e-9 → 上皮。
  （差 > 1e-9 即"不是上皮"；并列视为判据无分辨力，归非上皮。）
- **规则 `strict`**：在 `argmax` 之上再加两条 ——
  ① `{EPCAM, KRT7, KRT19}` 至少一个**检出**（count > 0）；
  ② `{PTPRC, CD3D, PECAM1, COL1A1}` **全部零检出**。

两条规则**同跑**，用于检验结论对定义是否稳健。**不得事后择一保留**；
若两者方向不一致，结论登记为"对上皮定义敏感"，并**停在检查点**。

## 4. 可证伪守卫（写进代码，不靠人看）

1. **EPCAM 富集守卫**：上皮集合的 EPCAM 检出率必须 ≥ 2× 集合外；否则 `stop()`。
2. **非空守卫**：上皮集合为 0 个细胞 → `stop()`。
3. **计数守卫**：`prediction.txt` 行数必须 == 进入 copykat 的细胞数（`ch$n_cells_used`）。
   （该守卫 2026-09-16 修过：原先比的是"过地板的细胞数"，地板为 0 时 copykat 自己的
   200 基因过滤器会合法地少删细胞，导致误炸，见 `ab_B_P14_Normal`。）

## 5. 判读标准（**执行前**定，防事后择果）

对每个样本并排报四组数：`全细胞 / 仅上皮(argmax) / 仅上皮(strict)`。

- **支持"谱系混杂是主因"**：仅上皮后，Normal 样本的"非整倍体比例"**大幅下降**，
  且两条规则的**下降方向一致**。
- **否定该假设**：仅上皮后比例**不降**（或两规则方向相反）→ 谱系混杂不是主因，
  必须回到 CopyKAT 内部链路重新定位，**不得**转而调地板/阈值来凑结果。
- **不做**的判断：**不设"低于某数值就算修好"的阈值**。那正是法则 3.2 禁止的事后调参。
  本臂只做**归因**（是谱系还是阈值），不做**验收**。

## 6. 本臂**不**产生的结论

- 不产生任何恶性判定。marker 判"是不是上皮"，CNV 判"这个上皮是不是恶性"——两个不同问题。
- 不构成 M2 的正式产物。**正式 M2 的输入上皮标签必须来自 M3 冻结的注释**（见 §7）。
- 不宣称管线已修好。本臂是**归因实验**。

## 7. 与主计划的关系（待裁决）

CopyKAT 需要上皮子集 ⇒ M2 依赖"哪些是上皮" ⇒ 依赖 M3 的注释。
故本臂**不是**把 M3 提前，而是**可行性归因**；正式排期是否改为
"M3 注释冻结 → M2 全量"须单独裁决并改 `PLAN_AND_CHECKPOINTS.md`。
若改为该顺序，须同时加一条硬约束：**M3 的注释只命名谱系，不许命名恶性**（恶性命名权只在 M2），
否则违反 R2。

# 附篇 · 单一亚型臂（2026-09-16 追加，**首跑之前**登记）

## A1. 为什么追加

§5 的判读已触发："两规则方向相反 → 登记为对定义敏感"。实测：

| 样本 | 全细胞 | 仅上皮 argmax | 仅上皮 strict |
|---|---:|---:|---:|
| P13_Normal | 40.7% | 0.0% | 0.0% |
| P11_Normal | 26.2% | 0.0% | **32.3%** |

对 `P11_Normal` strict 的 232 个上皮做 marker 谱，发现**判决轴换成了亚型**：

| 组 | n | SFTPC | SFTPA1 | AGER | PTPRC/COL1A1/PECAM1 |
|---|---:|---:|---:|---:|---:|
| 判"非整倍体" | 75 | 4.79 | 4.31 | 0.92 | 全 0 |
| 判"二倍体" | 137 | 2.12 | 1.73 | **2.88** | 全 0 |

即：**上皮判据生效了（免疫/基质全零），但 copykat 转而劈开 AT2 与 AT1。**
故上皮这一层不够，本附篇检验下一层。

## A2. 规则（逐字）

在 §3 的 `strict` 结果**之上**，按**独立的** AT1/AT2 marker 集再收窄一次：

- AT2 marker：`SFTPC, SFTPA1, SFTPA2, SFTPB, ABCA3, NAPSA, LAMP3`
- AT1 marker：`AGER, CAV1, PDPN, HOPX`
- 出处：Travaglini et al. 2020 *Nature* 587:619（Human Lung Cell Atlas）—— 与本计划
  M3 标准 B 所用的 `celltypist` Human_Lung_Atlas **同一来源**。
  ⚠️ 这组 marker 我是按该图谱常见引用写出的，**尚未逐字回原文核对**；若本臂成为承重结论，
  必须先回去核对并在此处补上原文页码。
- 判定：`at2_score > at1_score` 且 `{SFTPC, SFTPA1, SFTPB}` 至少一个检出 → 归 AT2。
  其余剔除。**不填补。**
- 该定义**独立于 copykat 的输出**（用的是图谱 marker，不是 copykat 分的簇），故不循环。

## A3. 预注册的判读（**执行前**定）

对 `P11_Normal`（Normal 样本）跑 AT2-only：

- **若判定 ≈ 全部二倍体（非整倍体率接近 0）** → 支持"基线靠猜 + 非同质输入"这一诊断，
  且给出**可用输入规格**：锚定 + 单一亚型。
- **若仍裂开（非整倍体率显著 > 0）** → **copykat 在本数据集上不可用**。
  必须改换方法：`Numbat`（SNP 等位基因定相，不需猜正常参考）或 `inferCNV`（强制 reference）。
  **不得**再调地板/阈值来凑。

**不设数值阈值**（法则 3.2）。本臂只做**归因**，不做**验收**。
