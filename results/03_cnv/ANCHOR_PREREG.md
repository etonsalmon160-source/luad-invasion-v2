## 1. 要回答的唯一问题

**在显式锚定 + 单亚型输入同时满足时，CopyKAT 给出的判决是不是方向正确且稳定的？**

三条判据（缺一不可）：

1. **锚定细胞（已知正常）被判 ≈ 全二倍体** —— 这是**阴性对照**；
2. **病灶细胞里有非零的非整倍体** —— 这是**阳性对照**（没有它，方法在检出端无功效）；
3. **同患者内方向一致**：病灶的"非整倍体比例"高于其配对 Normal。

### 为什么非做不可

2026-09-16 的归因实验（`GP1_report.md` §9.7–9.9）实测到的失效模式：

| 已跑过的臂 | 结果 |
| :--- | :--- |
| 全细胞 | Normal 样本判 26%–59% "非整倍体"，MIA 病灶 **0%** ⇒ 方向反了 |
| 仅上皮（两条规则） | 同一 `P11_Normal`：argmax **0.0%** / strict **32.3%** ⇒ 换定义就翻盘 |
| 仅上皮 + 传统锚定（非上皮当参考） | `P13_Normal` 仍判 **34.1%** ⇒ 方向没修好 |
| 仅 AT2（同质但**未**锚定） | `P11_Normal` 0%（n=124）**且** `P11_LUAD` **0%（n=160）** ⇒ **肿瘤样本里一个都没检出** |

⇒ 最后一行是关键：它既不能证明方法对、也不能证明方法错，它证明的是**探测不到东西**。
**锚定 + 同质从未同时施加过。** 本臂补上这一组合。

### 2.2 亚型标签

亚型标签取自 **GP8a 上皮 L2**（`results/04_integration/seurat_trad/epiA/clusters.csv.gz`
的 `harmony_res0.7_seed0` 列）→ 经

⚠️ **实测口径缺口（登记，不掩盖）**：128,091 里有 **127,654** 能挂上标签，

### 2.3 一次运行的细胞集合（本臂的核心定义）

对**每个患者 × 每个病灶样本**各成一次运行：

```
rawmat = { 该患者 Normal 样本的 <亚型> 细胞 }  ∪  { 该病灶样本的 <亚型> 细胞 }
norm.cell.names = { 该患者 Normal 样本的 <亚型> 细胞 }        ← 显式锚定，不是空串
```

- **同质**：矩阵里只有**一个亚型**（AT2 或 AT1），无其他谱系、无其他上皮亚型。
- **锚定**：基线**不由 copykat 猜**，由我们显式给出（源码 `copykat.R:136`
  `else if(length(norm.cell.names)>1)` 分支）。
- **锚定的合法性**：Normal 样本的肿瘤组织学邻近正常肺，其 AT2 是**非恶性**的常规参照。
  ⚠️ **本前提未被本数据独立验证**——它正是本臂的**被测假设**（见 §4 守卫 G1）。
- **不合并不同患者**；同一次运行内只含**同一个人的两个样本**。
- Normal 样本与病灶样本**同属** 128,091 签字集、同属一个亚型标签。

### 2.4 亚型与分期

| 项 | 取值 | 理由 |
| :--- | :--- | :--- |
| **主口径亚型** | **AT2**（127,654 中 83,635 核，占 66%） | LUAD 的细胞起源；**有检出阳性对照的可能** |
| **次口径亚型** | **AT1**（30,162 核） | AT1 基本不是 LUAD 起源 ⇒ 天然的**近阴性对照**：若 AT1 臂也大量判非整倍体，说明判决仍不是 CNV |
| 病灶分期 | 该患者的**全部**病灶样本，逐样本各成一次运行 | 不挑选；与"逐样本"纪律一致 |
| AAH / AIS | **照跑，但结果单列并标低置信度** | 用户 2026-09-17 签字要求；依据：CopyKAT 原文前提是 "stromal cells have diploid genomes"，**癌前病变无文献背书**（§M2 文献空白行） |

⚠️ 23 个患者**全部跑**，**不挑选患者**。挑选患者即为事后择果。

## 3. 参数：**一个都不改**

沿用 `docs/PARAMETERS_AND_SOURCES.md` §M2 现行值，与已签字件逐字一致：

```r
id.type="S", cell.line="no", ngene.chr=5, min.gene.per.cell=200,
LOW.DR=0.05, UP.DR=0.10, win.size=25, KS.cut=0.1,
distance="euclidean", genome="hg20", n.cores=1, output.seg="FALSE"
```

- **`UP.DR`**：走 `copykat` 默认 + 源码 `:57` 覆写，逐样本申报**有效值**
  （2026-09-16 已撤回"统一为 0.05"的提案，理由见该文件）。
- **`n.cores=1` 固定**：它是**结果相关**参数（实测改核数会改结果），不是加速旋钮。
- **覆盖度地板 840 保留**：它的作用是压**低覆盖度造成的假阳性非整倍体**，
  而假阳性正是本臂要消掉的东西 ⇒ 去掉它等于**放宽**判据（法则 3.2 禁）。
  ⚠️ **代价必须上报**：地板是在**全细胞**上标定的，用在 AT2 上会切掉大量细胞。
  逐患者上报 `地板前 / 地板后` 两个细胞数。
- **`min.gene.per.cell=200` 的退化处置**（与 §M2 预注册一致，不新增）：
  过地板后 <200 细胞 → 标 `not_testable`，**绝不填补为 Normal**；
  `n_cnv_pos==0` → **作为真实结果上报**，**不得**放宽 `KS.cut` 重跑。

## 4. 可证伪守卫（写进代码，不靠人看）

| # | 守卫 | 判据 | 越界后 |
| :--- | :--- | :--- | :--- |
| **G1** | **锚定纯度**（阴性对照） | 锚定细胞被判非整倍体的比例 | `> 0.50` → 该运行 `implausible`，**停下报告**；`> 0.10` → 打旗标并在报告里单列 |
| **G2** | **阳性对照** | 全部病灶臂是否**至少有一个**非零非整倍体 | 若**全部为 0** → 结论 = **本数据集上 CopyKAT 在检出端无功效**，**停下**，换方法；**不得**降阈值 |
| **G3** | **锚定分支确已走到** | copykat 日志含 `baseline is from known input` | 缺 → **硬停**（已有实现，`logged_known_normal`） |
| **G4** | **计数守卫** | `prediction.txt` 行数 == `ch$n_cells_used` | 不等 → **硬停**（已有实现） |
| **G5** | **锚定非空** | 锚定细胞数 ≥ copykat 自身 `baseline.norm.cl(min.cells=10)` | < 10 → **硬停**（已有实现，`n_usable < 10L`） |

⚠️ **G1 的两个阈值是「本项目约定」（⚠️C），无文献出处**。登记理由是必须有一个能
**在跑之前**说清的停机点，否则又变成事后解释；且 0.50 的含义明确：**基线自己多数被判非整倍体时，
基线无意义**。整条曲线一并上报，使读者能自行判断阈值移动时结论是否稳健。
