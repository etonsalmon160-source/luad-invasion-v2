### 1.2 门要求的"耗时-内存外推"

**给出区间，不给单一真值**（脚本：[`04_prereg_schedule.py`](../../03_cnv/04_prereg_schedule.py)；产物

用两个已回锚点（801 → 230.2 s；4,448 → 3,013.7 s）：

- 线性 `t = a + b·cells` **被否证且被排除**，两条独立依据：
  **(a)** 解出 `b ≈ 0.763 s/细胞、a ≈ −381 s` —— 负截距，对小样本会预测出**负时间**，非物理；
  **(b)** 源码核实 step 4 含**两次** O(n²) 的 `parDist`+`hclust`（`baseline.norm.cl.R:19-21`

- 剩两个**物理可容许**模型并列：`t = a + b·n²` 与 `t = c·n^α`。两点恰好定死两个模型，

  回代得 44.7 GB，与实测吻合。

## 2. copykat 判定链：`not.defined` 到底是什么

**这是本次最重要的方法学澄清。** `not.defined` **不是"算法对生物学不确定"**，而是
**覆盖度排除**：细胞的检出基因不足以覆盖全部染色体到规定深度时，被踢出分段。

源码 `tools/copykat/R/copykat.R` 的两段同构循环（`:86-105` = `ToRemov2`、`:194-213` = `ToRemov3`），
三条判据：

| # | 源码 | 真实语义 |
|---|---|---|
| ① | `length(as.numeric(cbind(chromosome_name, count))) < 5` | `cbind` 是**两列**矩阵，`as.numeric` 拉直后长度 = 2 × 检出基因数 → 字面"<5"实为「检出基因数 ≤ 2」 |
| ② | `length(rle(cell[,1])$length) < length(unique(anno.mat$chromosome_name))` | 检出的基因必须覆盖**全部**染色体（分母取**全集**，不是子集） |
| ③ | `min(rle(cell[,1])$length) < ngene.chr` | 任一染色体上的连续检出基因段长度 ≥ `ngene.chr`(=5) |

> 实现注记：基因已按 `abspos` 排序 → 同一染色体的基因连续 → `rle(chrom[hit])` 的段数 = 被检出到的
> 染色体数、段长 = 该染色体上的检出基因数。故 ②③ 可等价地向量化为一次稀疏矩阵乘
> （细胞 × 染色体 的检出计数矩阵），无需逐细胞 R 循环。已实测等价（见 §2.2）。

## 3. UP.DR 决策的依据

`copykat` 第 57 行是**无条件覆写**：只要 `der > LOW.DR` 剩下的基因 < 7000，传入的 `UP.DR` 就被改成 `LOW.DR`。
且 `UP.DR` 名不副实 —— 第 189 行是 `DR2 >= UP.DR`，它是**下界**不是上界。

**想让有效值全队列统一，唯一办法是令 `LOW.DR == UP.DR`**（否则覆写不可避免）。

### 3.1 队列分档（75 样本，来自 [`prereg_gene_tiers.csv`](prereg_gene_tiers.csv)）

`n_after_LOWDR_fullgenes`（= 7000 判据的分母）：min 3631 / p25 6737 / 中位 7680 / max 10376；
**< 7000 的样本 23 个（30.7%）**，这些样本的 `UP.DR` 会被改成 0.05。

> ⚠️ **订正（2026-09-16）**：本节早先写作"静默改成 0.05"，**不准确**。源码 `copykat.R:57-60`
> 在覆写的同时会 `print("WARNING: low data quality; assigned LOW.DR to UP.DR...")`，
> 并置 `WNS1 <- "low data quality"`。**这一步是响的，不是静默的。**
> 真正的静默陷阱只有 `:74-81` 的周期/HLA 删除与 `:65` 的注释丢基因（见 §2.3）。
> （`WNS1` 只进热图标题 `main=`，**不参与任何计算、也不在返回值里** —— 它是作者的
> 质量**标签**，不是质量**门**。）

覆写的**分期分布不是均匀的**：

| 规范分期 | 被覆写 / 该期样本数 | 比例 |
|---|---|---|
| Normal | 11 / 24 | **45.8%** |
| AAH | 1 / 9 | 11.1% |
| AIS | 3 / 14 | 21.4% |
| MIA | 2 / 4 | 50.0% |
| IAC(LUAD) | 6 / 24 | 25.0% |

> **这一条要盯着。** 覆写最集中在 Normal 期 —— 而 Normal 是整条梯度检验的锚。
> 若 GP2 不做统一，`UP.DR` 就会**与分期共线**：Normal 样本更容易用 0.05 的分段基因集，
> 其"恶性比例"因此与 IAC 样本**不可直接比较**。这是选择"统一阈值"的实质理由，
> 不是审美问题。

#### 🔴 但地板 840 之后，上面这条实质理由基本消失了（2026-09-16 实测）

地板作用在进 copykat **之前**，而 `n_after_LOWDR_fullgenes` 是**在细胞集上算的检出率**。
删掉低覆盖细胞 → 各基因检出率**升高** → 更多基因越过 `LOW.DR` → 判据分母**整体上移**：

| 量（75 样本） | 无地板 | **地板 840** |
|---|---|---|
| `n_after_LOWDR_fullgenes` 中位 | 7,680 | **9,136** |
| 该量 < 7000 的样本数 | **23 / 75（30.7%）** | **2 / 75（2.7%）** |
| 有效 `UP.DR` 分布 | 52 × 0.10，23 × 0.05 | **73 × 0.10，2 × 0.05** |

**21 个样本翻了档，且全部是 0.05 → 0.10，没有一个反向。** 仍被覆写的只剩两个：

| 样本 | 细胞数（地板后） | `n_after_LOWDR_fullgenes` | 距 7000 |
|---|---|---|---|
| `P16_AIS` | 1,471 | 6,949 | 差 51 |
| `P8_Normal` | 126 | 6,272 | 差 728（同时也是唯一的 `not_testable` 样本） |

**分期共线随之瓦解：**

| 规范分期 | 被覆写比例·无地板 | **被覆写比例·地板 840** |
|---|---|---|
| Normal | 11 / 24 = **45.8%** | **1 / 24 = 4.2%** |
| AAH | 1 / 9 = 11.1% | **0 / 9 = 0%** |
| AIS | 3 / 14 = 21.4% | **1 / 14 = 7.1%** |
| MIA | 2 / 4 = **50.0%** | **0 / 4 = 0%** |
| IAC(LUAD) | 6 / 24 = 25.0% | **0 / 24 = 0%** |

> ### ⚠️ 这**翻转**了"统一阈值"这笔账，理由如下
>
> **统一（令 `LOW.DR == UP.DR`）在数学上只有两个可能结果**：全 0.10 或全 0.05。
> 而 copykat 的覆写**只降不升**（`:57` 只在 `< 7000` 时把 `UP.DR` 改成 `LOW.DR`），
> 所以"全 0.10"**做不到** —— 统一必然意味着**把 `UP.DR` 定成 0.05**。
>
> | | 统一要动多少个样本 | 买到的均匀性 |
> |---|---|---|
> | **无地板时** | 52 个（把它们的 0.10 压到 0.05） | 从 31% 异质降到 0% |
> | **有地板时** | **73 个**（把它们的 0.10 压到 0.05） | 从 **2.7%** 异质降到 0% |
>
> **地板把"要动的样本数"从 52 涨到 73，同时把"买到的均匀性"从 31% 缩到 2.7%。**
> 也就是说：**这笔交易的方向反了 —— 代价变大、收益变小。** 同时它还直接违背作者 README
> 那句 "I need to make sure that LOW.DR is smaller than UP.DR"（§3.3(3)）。
>
> **我的建议随之改变**：不做统一，**保留 copykat 自身的设计行为**，改为
> ① GP2 **逐样本如实上报 `copykat_effective_UPDR`**；
> ② 把仅存的 2 个例外（`P16_AIS`、`P8_Normal`）**单独列出并加敏感性分析**
> （对这 2 个样本在 0.05 与 0.10 两档各跑一次，报结果差异）。
>
> **但这仍是你的决定，不是我替你钉的。** 证据方向已从上一次的"倾向统一"翻到"倾向不统一"，
> 请据此重新裁决；我不会把上一轮任何一版的结论当作已签。

### 3.4 附：`WARNING! NOT CONVERGENT!` 的真实来源（与 copykat 无关）

跑 copykat 时 stdout 里会大量出现：

```
number of iterations= 500
WARNING! NOT CONVERGENT!
```

**先说结论：这不是 copykat 的判据，也和"CNV 没算出来"没有任何关系。** 逐层查证如下。

**(a) copykat 自身完全没有"收敛"这个概念。** `tools/copykat/R/` 全树**搜不到** `converge` /
`CONVERGENT` 任一处。其 MCMC 实现 [`CNA.MCMC.R`](../../tools/copykat/R/CNA.MCMC.R) 是固定分割 +
调 `MCMCpack::MCpoissongamma` 采样，不含任何收敛判据，也**不打印任何东西**（全文只有一句被注释掉的
`#print(...)`）。

**(b) 那句话来自第三方包 `mixtools`。** 出处是 [`baseline.GMM.R:23`](../../tools/copykat/R/baseline.GMM.R:23)
—— copykat 对**每一个细胞**做的 3 分量高斯混合 **EM** 拟合：

```r
GM3 <- mixtools::normalmixEM(sam, lambda = rep(1,3)/3, mu = c(-0.2, 0, 0.2),
                             sigma = sg, arbvar=FALSE, ECM=FALSE, maxit=500)
```

`mixtools::normalmixEM` 函数体里的判据是**字面意义上的"迭代次数用满了没有"**：

| 行 | 代码 | 含义 |
|---|---|---|
| `:54` | `while (diff > epsilon && iter < maxit)` | 退出条件：对数似然增量 ≤ ε **或**撞上迭代上限 |
| `:125` | `if (iter == maxit) cat("WARNING! NOT CONVERGENT!")` | 撞上限就报这句 |
| `:128` | `cat("number of iterations=", iter)` | 所以 `500` = 撞限；`321`/`260`/`222` = 正常收敛 |

`epsilon` 是 mixtools 自己的默认 **1e-08**，copykat 只把 `maxit` 从默认 1000 改成 500。
**因此该警告等价于"这个细胞的混合拟合把 500 步迭代预算用完了"。**

**(c) 三件必须说清的事：**

1. **拟合结果照样被采信。** `:129` 之后无条件组装并返回 `lambda/mu/sigma`，copykat 直接读
   `GM3$mu`、`GM3$lambda` 做 diploid/aneuploid 判断。**警告不改变任何结果**，也不是错误。
2. **ε=1e-8 在 ~6000 个带噪点上过严**，撞限很常见 —— 所以"NOT CONVERGENT"既不罕见、也不等于判错。
3. **但它确实是一个边界柔性的来源。** 由于结果照样被采信，而 copykat 的判决线极细
   （`frq > Nfraq.cut`，`Nfraq.cut = 0.99`），没跑到 ε=1e-8 的细胞在边界附近**理论上可能翻面**。
   这是"diploid/aneuploid 边界不是硬真值"的又一条理由。这是 copykat 的设计，我们不事后调参
   （法则 3.2）。

> **我方产物中没有把它写成任何结论。** 全仓仅有 copykat 自己吐出的 `copykat.stdout.log`
> 保留了这句原文（原样捕获的第三方输出，非我方论断），`results/`、`docs/` 的正文一处都没有。

### 4.3 对 GP2 排期的硬约束

> **排期用的核数已核实（2026-09-16）**：`nproc` = **20**，但 `lscpu` 报 **96** —— 不矛盾：
> 本进程被限制在一个 **20 核 cpuset**（`taskset -pc` = `3,8,16,19,20,22,27,28,38,43,44,53,58,61,68,75,80,84,91,92`），
> 且 `cpu.max` = `max 100000`（**无时间配额**，限制来自 cpuset 而非 quota）。96 是**宿主机**的，
> 不归本项目。`parallel::detectCores()` 与 `detectCores(logical=FALSE)` 也都返回 20。
> **结论：排期的核预算就是 20，不可上调** —— 即 [`04_prereg_schedule.py`](../../03_cnv/04_prereg_schedule.py)
> 的 `CORES=20` 是**上限而非假设**。（RAM 实测 256 GB 总量 / 193 GB available。）

| 约束 | 值 | 含义 |
|---|---|---|
| 内存 | P24 单样本 **43.34 GB**（≈1.05 MB/细胞） | 计划里写的"20 核并行 8 个样本"会要 **344 GB > 256 GB** |
| 并行上限 | 由**内存**而非核数决定 | 200 GB 预算下同时只能放 **4** 个 P24 级样本（20 核用不满） |
| 单样本耗时 | 最大样本 **≈68.4 h**（quad 支） | power 支（23.6 h）**已被 P19 否证**，见 §1.2 |
| 全量成本 | **215 ～ 415 CPU·h**；LPT 排期挂钟 **35 ～ 77 h**（**待重算**） | 旧区间由两模型并列得出；power 否证后须用 3 锚点重跑，见下 |
| `n.cores` **不是**免费加速钮 | 见下方专段 | 改核数会**改结果**，不只是改速度 |

**结论：排期的驱动量是少数几个大样本，不是细胞总数。**

#### `n.cores` 为什么不能当加速旋钮用（本节更正了早前的一个错误说法）

早前本节写"`n.cores` 能帮 `parDist`（`threads=`）与 step 3（`mclapply`）"。**这半句是错的**，
必须区分两类并行点：

| 机制 | 位置 | 调 `n.cores` 的后果 |
|---|---|---|
| `parallelDist::parDist(threads=)` | `baseline.norm.cl.R:19`、`baseline.GMM.R:47`、`copykat.R:123/147/257…` | **结果中性** —— 距离矩阵是确定性计算，只是分几线程算 |
| `parallel::mclapply(mc.cores=)` | **`CNA.MCMC.R:73`**（MCMC 分段）、**`copykat.R:123`**（dlm 平滑） | **会改结果** —— 见下 |
| `hclust` | 全部调用点 | 结果中性，但**永远串行**，`n.cores` 对它**完全无用** |

`mclapply` 是 fork 式并行，子进程的随机流按 **child 序号**分配。于是 `mc.cores` 一变，
"第 i 个细胞拿到哪个随机流"就变。**已实测证伪**（在 20 核 / R 4.2.2 上）：

```r
probe <- function(cores) { set.seed(1234); unlist(mclapply(1:8, function(i) runif(1), mc.cores = cores)) }
identical(probe(1), probe(2))   # FALSE
identical(probe(1), probe(4))   # FALSE
```

`CNA.MCMC.R:73` 里每个细胞的 `MCpoissongamma` 正是用 RNG 的，所以**改 `n.cores` 会改每个细胞的
CNV 分段结果**。copykat 自己是装了种子的（`copykat.R:34 set.seed(1234)`、
`baseline.synthetic.R:38 set.seed(123)`），但那只保证**固定 `n.cores` 下**可复现，
不保证跨核数可复现。

> **对 GP2 的处置**：GP2 必须**全程固定 `n.cores`**（本门冒烟用 1），并把该值作为参数连同产物哈希登记。
> 若将来为了提速要改核数，那是**换了一个计算方法**，必须整批重跑，不能只重跑一部分 ——
> 否则同一队列里会混入两套互不可比的 CNV 结果。

## 8. 路线 A：覆盖度地板（负对照稀释实验）

**产物**：[`routeA/curve.csv`](routeA/curve.csv) · [`routeA/P13_Normal_routeA.json`](routeA/P13_Normal_routeA.json)

### 8.1 设计

问的不是"全样本 `not.defined` 有多少"（那只是常数底噪的堆叠），而是
**"一个已知二倍体的细胞，在多少覆盖度下会被判成 `not.defined`"**。

1. 取 `P13_Normal` 在**全深度**被判 `diploid` 的 **494** 个细胞作**负对照**（该样本为正常样本，
   全深度 `aneuploid` = 0）；
2. 对每个稀释比例 `f ∈ {1.0, 0.9, …, 0.2}` 独立做**二项稀释**（`rbinom` 逐计数抽样，各比例独立种子
   `SEED_BASE + f×1000`），重跑 `copykat`；
3. 主口径 = `rate_not_defined_neg` = 负对照中**被判 `not.defined` 的比例**（分母恒为 494，字面口径：
   被 `<200` 基因整细胞丢弃者**不计入分子**）；另报稳健性口径 `rate_unsegmentable_neg`（把整细胞丢弃
   也算作不可分段）；
4. 地板定义为**最大**的 `f` 使主口径率 > 0.50；`C*` = 该点负对照中位 `nFeature`。

|---|---|---|---|---|---|---|---|

### 8.5 诚实边界（这份曲线**不能**支持什么）

1. **n = 1。** 全部结论来自**单个** `P13_Normal`。没有第二个负对照样本，**没有生物学重复**。
2. **循环定义。** 负对照是 copykat **自己**在全深度的判定。所以本实验测的是"偏离 copykat 自己的
   全深度结论有多远"，**不是**偏离某个独立真值有多远。不能据此说 copykat 在全深度是对的。
3. **稀释 ≠ 真实低质量。** 二项稀释只模拟**测序深度下降**，不模拟环境 RNA 变化、双体率变化、
   细胞状态变化。因此真实低覆盖度样本只会**更糟**，本曲线是**下界**。
4. **0.50 这个切点是 ⚠️C 项目约定，无文献出处**（§3.3 已逐条核查过：作者文档中
   "可接受的 `not.defined` 率"与"最低细胞数"都**不存在**）。
5. **两种口径在本网格上并未真正分开。** `knee_absent_neg_at_f_knee = 0` —— 在 f ≥ 0.4 时没有负对照
   细胞被整细胞丢弃，所以字面口径与稳健性口径**数值相同**。也就是说稳健性口径**没有被真正检验**，
   它只会在 f ≤ 0.3 分岔，而那里 copykat 已经整个失败。
6. **`n.cores = 1`，且 `n.cores` 不是可自由调整的加速旋钮。** copykat 在 `copykat.R:34` 设了
   `set.seed(1234)`，固定核数下可复现；但 step 5 的 `CNA.MCMC`（`CNA.MCMC.R:73`）与 step 3 的 dlm 平滑
   （`copykat.R:123`）都用 `mclapply` 并行，**改核数会改变每个 fork 的 RNG 流 → 改变结果**。
   所以"提核数省时间"是拿结果换的。详细机制、源码位置表与**实测证伪**见 **§4.3 专段**。
   本门路线 A 的全部曲线都在 `n.cores = 1` 下产生，与冒烟锚点**同核数**，因此可比。

### 9.1–9.6 第一次修正：地板与有效 `UP.DR` 耦合（**归因已被取代，证据保留**）

**一句话**：840 地板把 `P13_Normal`（纯二倍体负对照）**自己**的有效 `UP.DR` 从 0.05 顶到 0.10，

### 9.2 机制：地板**是**翻转 `UP.DR` 的那个原因

`copykat.R:57` 的覆写判据是 `n_after_LOWDR_fullgenes < 7000`。地板剔掉低覆盖细胞 → 逐基因检出率**升高**
→ 过 `LOW.DR` 的基因变多 → `P13_Normal` 从 **6,695（<7000，被覆写成 0.05）** 变成
**8,138（≥7000，保住 0.10）**。所以**地板就是那个把样本从保守阈值推向激进阈值的操作**。

> 这同时**推翻**了 §8 采纳 840 的核心论证之一。§8 的稀释实验说"低覆盖度制造假阳性非整倍体"，
> 于是取更严的地板以压假阳性。**但稀释与地板是两件不同的事**：稀释是**把所有细胞**的覆盖度压低；
> 地板是**丢掉覆盖度最低的那批细胞、只留高的**。前者确实制造假阳性，后者的实测效果却是
> **把有效 `UP.DR` 推高、从而制造更多假阳性**。两者被当成了同一件事，这是我当时没看出来的。

### 9.7 第二次修正：根因是**基线靠猜**，不是谱系，也不是阈值

`P13_Normal` 与 `P11_Normal` 各跑了两条**都说得过去**的上皮判据（规则见
[`EPI_PREREG.md`](EPI_PREREG.md)，**执行前**登记）。结果：

| 样本 | 全细胞（地板840, `UP`=0.10） | 仅上皮 · argmax | 仅上皮 · strict |
|---|---:|---:|---:|
| `P13_Normal` | 160/393 = **40.7%** | 0/192 = **0.0%** | 0/80 = **0.0%** |
| `P11_Normal` | 192/733 = **26.2%** | 0/451 = **0.0%** | 75/232 = **32.3%** |

**`P11_Normal` 的两条规则给出 0.0% 与 32.3% —— 触发 `EPI_PREREG.md` §5 预注册的
"两规则方向相反 → 登记为对定义敏感并停在检查点"。**

**判决由"你喂了哪些细胞"决定，不由 CNV 决定。** 把细胞集**收窄**（451 → 232，本该只降噪）
反而把非整倍体**从 0% 抬到 32.3%** —— 任何稳健的 CNV 估计都不该有这种行为。

#### 收窄的到底是什么？—— 亚型

对 `P11_Normal` strict 的 232 个上皮细胞做 marker 谱：

| 组 | n | SFTPC | SFTPA1 | SFTPB | AGER | NKX2-1 | PTPRC | COL1A1 | PECAM1 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 判"非整倍体" | 75 | **4.79** | 4.31 | 4.31 | 0.92 | 2.34 | 0.00 | 0.00 | 0.00 |
| 判"二倍体" | 137 | 2.12 | 1.73 | 2.53 | **2.88** | 2.75 | 0.00 | 0.00 | 0.00 |

免疫/基质 marker **全部为零**——上皮判据生效了，这确实是纯上皮。
**但 copykat 仍然劈开了它：判"非整倍体"的是 AT2（表面活性物质高），判"二倍体"的是 AT1（AGER 高）。**

对照 `P13_Normal` argmax（0.0% 那臂）：它的 192 个上皮 **同时**带 AT2（SFTPC 3.88）与
AT1（AGER 1.97）——**是混合亚型，却被整份判成二倍体**。

**所以两侧都不是"答对了"**：一个是把亚型劈成非整倍体，另一个是把混合亚型整份放行。
两者都是同一个开关的两个极点。

#### 开关在哪：`copykat.R:456` 的二值分支

```r
cl.diploid  <- which(cl.ID %in% max(cl.ID))     # 与"猜出来的正常细胞"重叠最多的簇
cl.aneuploid <- which(cl.ID %in% min(cl.ID))    # 重叠最少的簇
if (cor(conses.diploid, conses.aneuploid) >= 0.6) {
    com.preN[1:length(com.preN)] <- "diploid"   # ← 全部细胞判二倍体
} else {
    ... 按 Wasserstein 距离把**每一个簇**强制分成 diploid / aneuploid  # ← 没有第三档
}
```

**链路上每一环都是猜的：**

1. `norm.cell.names=""`（我们的调用）→ 走 `baseline.norm.cl()` **自动猜**正常细胞（`copykat.R:166-170`）。
   猜法：`hclust(ward.D2)` 分 6 群 → 各群拟合三成分正态混合取 `SDM` → 取 **`SDM` 最小的簇**当正常。
2. 实测：这条自动猜 **13 个臂里 10 次**打印 `low confidence in classification`（其判据是
   `silhouette(k=2) <= 0.15` 或 F 检验 p > 0.05）。打印之后它**不拒绝作答**，而是静默回退到
   `baseline.GMM(max.normal=5, ...)` 重取 `preN`，并把 `WNS` 改写成 `""` —— 于是最终标签带着
   **确定的措辞**输出，日志里的那句低置信只剩在 stdout。
3. `preN`（猜出来的"正常"）就是 `cl.diploid` 的定义锚点。
4. :456 是**二值**的，且 `else` 分支**没有"不确定"这一档**。

**横竖与 CNV 无关：判决 = f(输入细胞群的表达主轴, 猜出来的基线, 一次二值判断)。**

> **未测**：我没有插桩去实测每次跑的是哪个分支（需要改 copykat 内部）。
> 上面是**源码事实 + 观测模式**的推论，不是直接测量。可观测的签名是：同一份数据，
> 收窄细胞集就从 0% 跳到 32.3%。

| 1 | "地板把假阳性从 0% 抬到 41%" | **我自己的脏对比**：两臂同时变了细胞集与 `UP.DR`，无法归因 → 补臂② |
| 2 | "`UP.DR_eff` 是主因" | `P13_Normal` 在地板 + **统一 0.05** 下仍 **163/393 = 41.5%**（vs 0.10 的 160）→ 阈值不是主因 |
| 3 | "谱系混杂是主因，剔掉非上皮就好" | `P11_Normal` argmax **0%** vs strict **32.3%** → 亚型混杂接棒 |

**这三次没有一次是猜的，都是下一步实测打脸。** 保留记录，不删。

### 9.9 对本计划的三条硬结论

1. **上皮子集既非必要也非充分**，GP2 不得以"已改为仅上皮"为由放行。
2. **上一轮我给的"改报连续 CNV burden、丢掉二值标签"这条建议，我撤回。**
   基线猜错时，`final_results_bin_by_cell.txt` 整张 CNA 矩阵都是**相对错误基线**算的 ——
   连续化只能消掉 :456 那个二值悬崖，消不掉基线错误本身。
3. **唯一有出处的出路是"锚定 + 同质"两条同时满足**：
   · **锚定**：显式给 `norm.cell.names`（copykat 文档用法），不让它猜；
   · **同质**：输入必须是**同一亚型**的 恶性 + 正常 混合。
   只做锚定不够——若输入里 AT1/AT2 并存、而参考是其中一种，另一种照样被判非整倍体。

   **可证伪的下一步（尚未跑）**：把 `P11_Normal` 的输入收窄到**单一亚型**（如 AT2 高表面活性物质那簇），
   预期 Normal 样本 → 全部二倍体。**若仍裂开，则 copykat 在本数据集上不可用**，须改用
   `Numbat`（靠 SNP 等位基因定相，不需要猜正常参考）或 `inferCNV`（强制提供 reference）。
