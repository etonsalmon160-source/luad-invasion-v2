## 一句话结论

**方向第一次对了，但样本量只够冒烟，不足以判"方法可用"。**

病灶侧第一次跑出非零的恶性信号（IAC 侧 30.6%），而锚定侧两次都是 0%。这是本数据集上
第一次出现"病灶 > 正常"的方向。**但**这个结论全部压在一个样本的一根柱子上（G2 的阳性对照
只有 P11_LUAD 这一根非零），所以它**只说明"锚定这条路值得往下走"，不说明"方法可用"**。

## 1. 两次运行的分侧结果

| 样本 | 送进 CopyKAT | 锚定侧（P11_Normal，AT2） | 病灶侧 | G1 |
| :--- | ---: | :--- | :--- | :--- |
| **P11_LUAD**（IAC）| 728 核（571 病灶 + 157 锚定）| **0 / 157 = 0.0%** | **175 / 571 = 30.6%** | ok |
| **P11_AAH** | 585 核（428 病灶 + 157 锚定）| **0 / 157 = 0.0%** | **0 / 428 = 0.0%** | ok |

判定明细（逐细胞，可核对）：

- P11_LUAD：728 = 非整倍体 **175** + 二倍体 509 + 未定义 44
- P11_AAH：585 = 非整倍体 **0** + 二倍体 568 + 未定义 17

**"未定义"是 CopyKAT 明说判不了的那一档，不是"正常"。** 它单独列出来，没有被并进任何一边。

## 2. 五条守卫（跑之前写好的，不是事后挑的）

| # | 判据 | P11_LUAD | P11_AAH |
| :--- | :--- | :--- | :--- |
| **G1** 锚定纯度（阴性对照） | 锚定细胞被判非整倍体的比例 | **0.0%** → ok | **0.0%** → ok |
| **G2** 阳性对照 | 病灶臂是否至少一个非零 | **175 ≠ 0** → 过（**但只有这一根**）| 0 |
| **G3** 锚定分支确已走到 | 日志含 `baseline is from known input` | ✓ | ✓ |
| **G4** 计数守卫 | 判定行数 == 送进核数 | 728 == 728 ✓ | 585 == 585 ✓ |
| **G5** 锚定非空 | 锚定细胞数 ≥ 10 | 157 ✓ | 157 ✓ |

**G1 的含义（生物学上说）：** 基线是拿"已知正常"的细胞自己的表达谱做的。如果这批细胞自己
多数被判成非整倍体，那这个基线本身就没意义、后面所有判定都不能信。**结果是 0/157，一次都没误判
——基线可信。** 这是本臂能往下走的前提。

**G2 的含义：** 一个检出方法，如果在明显有肿瘤的样本上连一个阳性都报不出来，那它在这个数据集上
就是没有检出能力的。**P11_LUAD 报出 175 个阳性，所以 G2 过了。** 但要说清：判"过"的依据是
**两根柱子里只有一根非零**，这是 G2 能过的最低限度。

## 4. 一次意外的对照：锚定关 vs 锚定开（**不是预注册臂**）

🔴 首跑因一个实现 bug，锚定被静默清空，CopyKAT 于是走了"自己猜基线"的路。这一次留下的产物
被当作**意外对照**。**它不是预注册的臂，不得当正式结果引用。** 但它恰好证明了锚定的作用：

| 同一批 728 个核 | 病灶侧 | 锚定侧 |
| :--- | :--- | :--- |
| 锚定**没**传进去（首跑，意外）| 9.8%（56/571）| 0.0% |
| 锚定**传进去**（预注册的正式跑）| **30.6%**（175/571）| 0.0% |

**同输入、同参数，唯一变量是锚定。** 差别不是噪声，是锚定本身。

## 6. 诚实边界（**不能**从这次跑里得出的结论）

- ❌ **不能说"CopyKAT 可用"**。预注册 §9 就写明 P11 是冒烟；G2 的阳性对照全部压在 P11_LUAD 一根柱子上。
- ❌ **不能说"AAH 没有恶性细胞"**。0/428 是**空结果（NULL）**，不是阴性结论：
  报不出 ≠ 不存在。尤其 AAH 是早期病变，本来信号就弱。
- ❌ **不产生任何恶性判定，不命名肿瘤细胞。** 本臂的产物是"方法的可用性判断"，不是细胞标签。
- ❌ **不构成 M2 正式产物。** GP2 门仍须独立签字。
- ⚠️ **一个已登记但没修的偏差：** CopyKAT 日志说 `152 known normal cells found`，我们传的是 157。
  源码里这个数是拿**平滑后**的矩阵数的，所以有 5–6 个锚定细胞被它自己从基线中位数里剔掉了。
  也就是说基线实际是 152 个细胞建的，不是 157。**登记在案，没有去修它。**

840 覆盖度地板是**本臂最大的一刀**，比亚型收窄、比用户签字集都狠：

| 样本 | 全样本核数 | 过 840 地板 | 保留率 |

| P11_Normal（锚定源）| 2,083 | 733 | 35% |
| P11_LUAD（IAC）| 10,179 | 4,847 | 48% |
| P11_AAH | 3,813 | 1,705 | 45% |

⚠️ 地板专门砍掉**低覆盖度**的核，而早期病变（AAH）的核 UMI 天然偏低。
所以**不能排除**：地板把一些真的带 CNV 的 AAH 核给砍掉了。

**但法则 3.2 禁止事后调参数**，所以我没有动这个地板。
如果要知道被砍掉那批核长什么样（覆盖度分布、AT2 marker 表达），可以**只描述、不改口径**地查一次 ——
这件事我提过，**等你决定做不做**。
