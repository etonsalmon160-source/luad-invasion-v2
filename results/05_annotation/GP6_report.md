## 1. 门判据与结果

预注册判据（`PLAN_AND_CHECKPOINTS.md` GP6）：

| κ 区间 | 处置 | 本例 |
| :--- | :--- | :--- |
| ≥0.80 且 ≥90% 簇通过 | 通过 | ✅ **κ=0.8539 → PASS** |
| 0.60–0.80 | 标记 + **强制人工复核** | — |
| <0.60 | 停 | — |

**两套标准的确是两个口径**（非自证）：

- **标准 A** = 法则2 规范 marker 面板（一次文献：Travaglini 2020 / Vieira Braga 2019 / Habermann 2020 / …）
  → `sc.tl.score_genes` 模块分 → 簇均值 argmax。基因来源**刻意排除 HLCA 整合图谱**。
- **标准 B1** = `CellTypist` `Human_Lung_Atlas`（HLCA，Sikkema 2023 *Nat Med* 29:1563，61 型）
  → 逐细胞多数投票。
- **标准 B2** = `rank_genes_groups('wilcoxon')` top-50 × 图谱 marker 集 Jaccard（topn=50，atlas_marker_topn=20）。

## 2. ⚠️ 三方一致率只有 7/45 —— 已定位，**不是 38 个簇标错**

看逐簇 argmax 的两两一致：

| 对比 | 一致簇数 |
| :--- | :--- |
| **A vs B1** | **41 / 45** |
| A vs B2 | 7 / 45 |
| B1 vs B2 | 8 / 45 |
| 三方全一致 | 7 / 45 |

**在 38 个"三方不一致"的簇里，A 与 B1 彼此仍然一致的占 34 个。**

⇒ 落后的**只有 B2**。B1 的逐簇一致率中位 **0.882**（分布 0.011–0.999）是健康的；
而 **B2 的 Jaccard 值全域只在 0.0086–0.0821 之间，中位 0.0446** —— 这个区间内的 argmax
**没有区分度**，等于在噪声里挑最大值。

**结论：`tri_agree = 7/45` 反映的是 B2 这条腿不可用，不是 38 个簇被标错。**
主判定以 A↔B1 的 κ=0.8539 为准。

**处置：不重调 B2。** 法则 3.2 —— 阈值与口径一经确定不得事后调整。把 B2 调到"好看"就是
p-hacking。B2 如实降级为**记录性指标**，在报告里写明其不可用及原因。

## 3. 面板缺基因 —— 已找到根因（数据源本身缺基因，非本项目丢失）

`gp6_metrics.json` 记录 `panel_missing`：上皮 `[KRT18, SFTPA2]`、T/NK `[CD8B]`、髓系 `[FCN1]`。

2026-09-17 追查到源头：**作者上传的 GEO 计数矩阵本身就只有 18,082 个基因**，
且按基因组位置排序（`SAMD11` chr1p36.33 → … → `MT-CYB` chrM）。上述 4 个基因
**在原始 `.raw_counts.mtx.txt.gz` 里就不存在**（逐个 `grep -cx` 验证 = 0）。

同时确认缺失的还有：**GAPDH、全部 RPL\*/RPS\* 核糖体基因（0 个）、MALAT1、TPI1、PTMA、
MT-CO1** 等；而 `ACTB`、`EPCAM`、`NKX2-1`、`SFTPC`、`AGER`、`FOXJ1`、`TP63` 等**均在**。

- 对**注释**的影响：4/63 面板基因不可用，已在指标中显式记录，未静默替换成别的基因。
- 对**CNV**的影响：见 `PARAMETERS_AND_SOURCES.md` 的基因注释表行 —— CopyKAT 的 96.03%
  覆盖率是**相对这 18,069 个基因**算的，**不是相对全转录组**。真实比例约 49%（18,082 / 36,601）。
  此前的表述需按此更正。
- 溯源状态：已派调研核对源论文方法是否说明了该参考/过滤规则；**未出结论前一律记为
  「未说明的基因集裁剪」，不得假设成因**（法则 0：静默默认陷阱）。
