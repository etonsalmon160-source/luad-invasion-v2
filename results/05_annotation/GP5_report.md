## 一、这道门在判什么

用一句话说：**每个谱系要切成几个簇，切多细。**「切多细」由 Louvain 的**分辨率**这个旋钮控制——数字越大切得越碎。

论文给的是**区间**而不是一个数：*"'FindClusters' function with a resolution set to 0.5-0.8"*。
所以本项目的做法是：**在这个区间里穷举四档（0.5 / 0.6 / 0.7 / 0.8，步长 0.1）**，再按预注册规则挑一个。

预注册规则（`PARAMETERS_AND_SOURCES.md` §M3-A.3，**跑之前就写死**）：

```
score(r) = 0.5 · ARI_跨种子(r) + 0.5 · ARI_跨分辨率(r)
硬约束①  ARI_跨种子(r) ≥ 0.90
硬约束②  aah_absorption_rate(r) ≤ 0.50
r* = argmax score，受①②约束
破平    两档 score 差 < 0.01 ⇒ 取**较低**分辨率
无解    停在检查点，不放宽阈值
```

**这两项指标的中文意思**：

- **跨种子**：把随机起点挪 5 次（种子 0/1/2/3/4），看同一个分辨率切出来的簇还认不认得出是同一批。认得出 = 这个刻度结实。
- **跨分辨率**：相邻两档（0.5↔0.6↔0.7↔0.8）切出来的结果像不像。像 = 这一带是个"稳定平台"，不是悬崖边。

**⇒ 签字 `r*` 仍不等于「指标3 支持了 `r*`」—— 它没有。**

### 6.1 原理：它在问什么

**一句话**：切完之后回头问一句 ——「我们给每个簇起的名字，**那个簇本身撑不撑得住**？」

判据的两半，缺一不可：

| 那半 | 大白话 | 为什么必须同时要 |
| :--- | :--- | :--- |
| **≥25% 的细胞里检出** | 这套 marker 得**真的在这个簇里表达**，不能只有三五个细胞在喊 | 防「少数细胞把均值拉上去」 |
| **模块分均值 > 0** | 该簇对这个 marker 集的**平均表达水平要高过随机对照基因集** | 防「表达量高纯粹因为测序深度」 |

两个条件一起，才叫「这个簇**认得出**」。覆盖率 = 认得出的簇 ÷ 全部簇，要求 **≥ 0.90**，
即最多允许 10% 的簇「谁也认不出来」。

🔴 **2026-09-21 更正（我此前说错过了）**：本报告初稿、以及登记表与脚本注释里都写着
「指标3 **必须等注释之后**才算得出来」。**这话只对收紧口径成立，对登记字面是错的。**

登记字面是「有 **≥1 个**法则2 marker 集……」，即**任意一套 panel 认得出即可**，
**并不要求知道该簇是哪一类** ⇒ 只要有簇、有表达矩阵就能算，**与注释无关**。
「必须等注释」只适用于 §6.2 建议收紧的「**本谱系那套**」口径 —— 而那个口径也只需要知道
**子集属于哪个谱系**（由子集定义直接给出），**同样不需要注释**。
（真正非等注释不可的，是更细的一层：要求「该簇必须被认成我们给它起的那个名字」。属 §6.2 的深层缺陷。）

### 6.2 ⚠️ 诚实说：它挡得住什么、挡不住什么

**这一段是注册文案与实际能力对不上的地方。**

| | 内容 |
| :--- | :--- |
| **挡得住 —— 「垃圾簇」** | 低质量细胞堆成的簇（深度不足 / 环境 RNA 污染）、双重体簇、细胞周期驱动的簇、两边都不像的中间态 |
| **挡不住 —— 「把真类型劈成两半」** | 把 AT2 切成「AT2-高」「AT2-低」，**两半都还在表达 SFTPC** ⇒ 两半都认得出 ⇒ 覆盖率 100% ⇒ **照样过** |

**⇒ 注册文案写它防「过切分」，严格讲不成立。它实质上是垃圾簇探测器，不是过切分探测器。**

还有一处更松：原文写「至少**一套** marker 认得出」—— **被错认也算认得出**（上皮碎片被 T 细胞面板「认出来」也算通过）。

🔴 **这两点必须在 GP8 钉死**：
1. 判据改成「必须是**本谱系那套** marker 认得出」，它才真正变成对注释的自洽检查（我们叫它 T 细胞，它得像 T 细胞）；
2. **改判据属改规则，须事前批准并重登记**，不得边跑边改。

**两种口径下「不过」的含义完全不同**：

| 口径 | 不过意味着 |
| :--- | :--- |
| 「任意一套认得出」（现行字面） | 就是**垃圾簇太多** |
| 「本谱系那套认得出」（建议改的） | 要么垃圾簇太多，要么**名字起错了** |

### 6.3 不过的后果

**规则层面**：按预注册，该分辨率**不得作 `r*`**，须**停在检查点、不放宽阈值、升级**。

**实际层面**（带着 10%+ 认不出的簇走下去）：

1. **注释会留下「未知」簇**，这些细胞进了细胞类型图谱却是黑户。
2. 🔴 **最重的一条**：按项目约定，**上皮亚型边界是 SCMG 迁徙的起点/终点定义**。
   若上皮的簇有一部分认不出来，那些「迁徙端点」就是虚的 —— **SCMG 分支的地基不稳**。
3. 下游任何建在这些标签上的差异表达 / 轨迹分析，全部继承该问题。
4. 成纤维的放宽先例会**被稀释**：若上皮也带着一堆未知簇过关，「探索性」这个标签就失去区分度。

### 6.4 如果不过、又已到边界，一般怎么处理

**先归因，不要直接动分辨率。** 看那些认不出的簇的 **top marker 是什么**：

| top marker 指向 | 诊断 | 一般做法 |
| :--- | :--- | :--- |
| 一个**已知类型，但不在我们面板里** | **面板不全**，不是分辨率问题 | **扩面板**（从权威文献补 marker）。**最该先查**，且不影响 `r*` |
| **核糖体 / 线粒体 / 环境 RNA / 细胞周期基因** | 真·垃圾簇 | **合并到最近邻簇**或剔除；**必须登记为一次明确的合并步骤**，不许偷偷并 |
| **两个已知类型各占一半** | 真实过渡群 | **单独命名并登记**为过渡态，不算失败 |
| 什么都没富集 | 碎片 | 合并 |

归因完仍不行，只剩三条路，**按代价从小到大**：

1. **合并簇（merge）** —— 切细后再按 marker 归并。**图谱界的常规操作**（先切细、再眼看 marker 并簇/命名），
   须作为**一个独立步骤**登记在案。
2. **扩网格到论文区间外**（0.2/0.3/0.4）。论文给的是 0.5–0.8，**往下走即出配方** ⇒ 须登记为偏差；
   且属**改判据，须事前批准**。
3. **降级为探索性结论** —— 同成纤维处理，报告里明写「该层有 X% 的簇无法归因」。

**绝对不做**：调低 0.90 阈值、挑几套好看的 marker 凑覆盖率、事后改指标定义。**那就是 p-hacking。**
