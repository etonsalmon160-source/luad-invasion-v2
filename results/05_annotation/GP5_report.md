## 一、这道门在判什么

用一句话说：**每个谱系要切成几个簇，切多细。**「切多细」由 Louvain 的**分辨率**这个旋钮控制——数字越大切得越碎。

论文给的是**区间**而不是一个数：*"'FindClusters' function with a resolution set to 0.5-0.8"*。
所以本项目的做法是：**在这个区间里穷举四档（0.5 / 0.6 / 0.7 / 0.8，步长 0.1）**，再按预注册规则挑一个。

预注册规则（`PARAMETERS_AND_SOURCES.md` §M3-A.3，**跑之前就写死**）：

```
score(r) = 0.5 · ARI_跨种子(r) + 0.5 · ARI_跨分辨率(r)
硬约束①  ARI_跨种子(r) ≥ 0.90
硬约束②  aah_absorption_rate(r) ≤ 0.50
r* = argmax score，受①②约束
破平    两档 score 差 < 0.01 ⇒ 取**较低**分辨率
无解    停在检查点，不放宽阈值
```

**这两项指标的中文意思**：

- **跨种子**：把随机起点挪 5 次（种子 0/1/2/3/4），看同一个分辨率切出来的簇还认不认得出是同一批。认得出 = 这个刻度结实。
- **跨分辨率**：相邻两档（0.5↔0.6↔0.7↔0.8）切出来的结果像不像。像 = 这一带是个"稳定平台"，不是悬崖边。

## 五、🔴 成纤维谱系：事后放宽了阈值

这是本报告唯一一处**违反"无解则停"**的地方，必须单独讲清楚。

| 项 | 值 |
| :--- | :--- |
| 预注册阈值 | ARI_跨种子 ≥ **0.90** |
| 四档实测 | 0.8331 / 0.7435 / 0.7999 / **0.8698** ⇒ **全部不达标** |
| 按预注册规则的应然结果 | **停在 GP5，不选 `r*`，升级给用户** |
| 实际结果 | **放宽到 0.85**，只有 0.8（0.8698）过线 ⇒ `r* = 0.8`，34 簇 |
| 授权 | 用户 2026-09-17 裁定 |
| JSON 留痕 | `relaxed: true`，`seed_min_applied: 0.85`，`seed_min_preregistered: 0.90`，`relaxed_note` 写明"只能作探索性结论，不得进主结论" |

**这意味着什么**（大白话）：成纤维这层的簇边界本来就松——把随机起点挪一下，两批划分的 ARI 只剩 **0.87**，明显低于我们给其余五个谱系设的 0.90 底线。**放宽阈值不是把它修好了，是承认它测不出稳定结构，然后明知如此仍往下走。**

> ⚠️ **不要把 0.87 翻译成"多少比例的细胞换了归属"**——ARI 不是百分比指标，本轮也没测细胞级别的换归属率。文献里那个"25%–46% 细胞换归属"的数字来自别处的 Seurat-Louvain 实测（SABER 预印本），**不是本数据集的数**，不得挪用。
>
> 一个**未验证的推测**：肺成纤维是连续活化的谱系（静息→肌成纤维→肌成纤维母细胞），本就无清晰分界。**这是推测，不是本门的结论。**

**因此**：
- 成纤维的 `r* = 0.8` 产物 **只能作探索性结论，不得进主结论**。
- 注释脚本会打红字（`check_rstar_signature` 检测到 `relaxed: true`）。
- **不得**在任何稿件里写成"成纤维亚群按稳定性最优分辨率划分"。

**顺带一个必须记录的分叉**：`results/04_integration/seurat_trad/fibroA/run_manifest.json` 里的
`rstar_candidate` 仍是 **`"NA"`**、`rstar_status` 仍写着 **"区间内无可行解 ⇒ 停在 GP5，不放宽阈值"**
—— 那是 R 脚本按**预注册阈值**写下的、**正确**的结论。而 `fibroA_rstar.json` 写的是 **`r* = 0.8`（relaxed）**。
**两者不矛盾**：前者是"按预注册规则的结果"，后者是"经用户裁定放宽后的结果"。JSON 里的
`rstar_authoritative_over` 字段已声明"以 JSON 为准，manifest 的 `is_rstar` 列全 FALSE 属预期"。
**本报告是这对分叉的权威说明。**

## 六、指标3（谱系覆盖）从未参与 `r*` 选择 —— 登记在案的口子

预注册规则写了**三条**硬约束（指标 1 / 3 / 4）。**指标 3（谱系覆盖 ≥ 0.90）本轮一次都没算过。**

原因：指标 3 的定义是"有 ≥1 个规范 marker 集被检出的簇占比"，**它需要先有注释**才知道哪个簇是什么。所以它在 r\* 选择阶段**算不出来**。

按 §M3-A.3 第 242 行的裁定（用户 2026-09-17 签字）：
指标 3 **留待 GP8 注释阶段逐谱系补算**；若届时某谱系 < 0.90，该分辨率不得作 `r*`，**须停在检查点升级**。

**⇒ 签字 `r*` ≠ 指标 3 已通过。** 它是一个**尚未关闭的检查点**。如果上皮 24 簇里有太多簇找不到规范 marker，0.5 这个刻度就要重新审。**这一点必须在签字时被明确认知。**

## 七、指标4（AAH 吸收护栏）本轮空转

| 项 | 值 |
| :--- | :--- |
| 定义 | 簇中 Normal 细胞占比最高且 >50% ⇒ 该簇为 Normal 主簇；`absorption_rate` = AAH 核落进 Normal 主簇的比例 |
| 硬约束 | ≤ 0.50 |
| 实测量 | **七次 run、全部 28 个（7×4）分辨率下，`aah_absorption_rate` 一律 = 0** |
| 原因 | 没有任何簇满足"Normal 占比最高且 >50%" ⇒ **分母为空**，按定义恒为 0 |
| ↳ **精确复核（2026-09-17，从 `clusters.csv.gz` 的 `stage` 列直算）** | **Normal 为众数的簇确实存在**（r=0.5/0.6/0.7/0.8 分别 **2 / 3 / 1 / 3** 个），但它们的 Normal 占比只有 **30.71% / 32.78% / 31.63% / 33.77%** —— **卡在「>50%」这半条上，不是「主导簇不存在」**。全量分期构成：IAC 188,087（45.5%）/ Normal 94,506（22.8%）/ AIS 81,555（19.7%）/ AAH 35,283（8.5%）/ MIA 14,266（3.4%） |
| ⇒ **为什么 50% 这个门槛在本设计里几乎不可能达到** | **分期是「样本」的属性，簇是「细胞类型」的划分**。同一个细胞类型的簇里混着各个分期的细胞，而 IAC 是最大的一员（45.5%）⇒ 任何细胞类型簇都很难让 Normal 过半。**要让 Normal 过半，必须让分期去驱动聚类** —— 那正是批次/混杂污染，是我们要避免的。**所以这个护栏的触发条件在正确整合的对象上结构性地够不着**（本条为本报告的分析，可由上表复算） |

**⇒ 该护栏没测到任何东西。它出现在每张表的 `pass_aah = TRUE` 里，但那个 TRUE 是无意义的**（分母为空）。**不得**把它计入 `r*` 的通过理由。

用户 2026-09-17 已裁定：**承认其在全量规模上无效**，保留登记但标记"全量无效"，不删除、不重设计。
⚠️ 将来若在别的数据/粒度重启，须**重新预注册**；**不得**把"全量空转"当作"子集上也必然空转"的理由。

> 注：亚聚类 run（六谱系）的 manifest 里 `metrics_caveat` 写明，子集口径下该列的语义是**全量口径的投影而非同一定义**，**不与全量值直接比较**。

## 九、我们的规则比文献严在哪、自定在哪（诚实定位）

**不是照抄任何一篇。** 逐条摊开：

| 我们做的 | 定位 |
| :--- | :--- |
| 在论文区间内穷举四档，而不是手调一个数 | **比图谱实践严**（他们手调） |
| 用跨种子稳定性当主判据 | **方向与 ClustAssess 同源**，但那是预印本；**轴也不同**（我们 ARI，它 ECS） |
| 0.90 硬底线 | 🔴 **纯属本项目自定**，无文献出处。**只能写成"本项目预注册护栏"** |
| 0.5·种子 + 0.5·分辨率 的加权 | 🔴 **纯属本项目自定**（两个权重都是拍的） |
| 差 <0.01 取较低分辨率 | 🔴 **纯属本项目自定**，且见 §四：**七次里拍板三次** |
| "选一个代表性种子" | 🔴 **本项目发明**，无权威先例。最近者是 ClustAssess 的"最频繁划分"——那是**共识众数，不是代表性种子** |

**规则里一条硬约束全空转（指标4）、一条从未施加（指标3）、一条被事后放宽（成纤维），而加权和破平两条判据都是自定的。** 这是本门最该被质疑的地方，在这里明写。

**审稿人若问，站得住的答法**：把「分辨率 × 稳定性」整张格子（本报告 §二/§三 的两张表 + `figures/rstar_candidates_by_lineage.png`）作为补充材料交出去；引 chooseR 与 ClustAssess 作先例，说明我们用 ARI 是**等价取向**而非照抄；**0.90 与破平规则说明是预注册的项目内部护栏**。**不要**写成"按文献方法选择分辨率"。

## 十二、关于种子（不在本次签字范围内，但必须说清）

- **要签的是刻度（`r*`），不是种子。** 种子是拿来"试刻度结不结实"的尺子。
- 注释阶段实际用的是 **`--seed 0`**（`03_subcluster_annotation.py` 的默认值）。
- **"种子 0 最有代表性"这个结论只在全量上算过**（GP6 报告：种子 0 对其余 4 个种子的平均 ARI 最高）。
  **六个谱系上并未复核。** 🔴 **登记为已知缺口** —— 若某一谱系里种子 0 恰好是最差的那个，注释结果会偏。
- 种子本身无对错；写进方法只为可复现。
