## 5. 诚实记录：本次构建的第一次运行**失败过**

第一次运行崩在 `KeyError: "['cell_barcode'] not in index"`。**根因已实测复现**（非猜测）：

`ad.AnnData(...)` 构造时**就地持有同一个 obs DataFrame，不做复制**；脚本中为清理索引名而写的
`adata.obs_names.name = None` 因此把 `obs.index.name` 置成了 `None`，导致其后的
`obs.reset_index()` 产出列名为 `'index'` 而非 `'cell_barcode'`。两行 pandas 即可复现：

```
set_index 后 index.name = 'cell_barcode'
置 None 后 reset_index() 的列 = ['index', 'x']
```

**关键：崩溃未污染数据。** 写 h5ad 那一步是**成功**的（日志有 `写出 ... (1.91 GB)`），
崩的是其后的 mask CSV 步骤。失败运行日志留档：`logs/Step0_build_expression.run1_FAILED.stdout`。
**修复**：在 AnnData 接管 obs **之前**把 mask 数据固化为独立副本 `mask_df`，并加 `len(mask_df) != EXPECT_N_OBS` 硬断言。
重跑全程 1238 s，结果与第一次的 h5ad 逐项一致（V1/V2/V3/V3b 全同）。

## 6. 这道门**不能**证明什么（边界声明）

1. **不重新验证 M1 的 QC/双体判定本身**。V2/V3 是把重建矩阵与 M1 的表**对齐校验**，两方源自同一批原始文件——
   它能抓住 barcode 错位、转置、漏样本、多样本，但**抓不住 M1 自身的系统性判定错误**。M1 的可靠性另见
   `results/01_qc/M1_validation_report.md`。
2. **不证明基因身份正确**。只证明了 75 个文件之间基因向量一致且无重名；"第 i 行确实是 SAMD11"依赖上游 GEO 文件本身。
3. **不含任何归一化/环境 RNA 校正**。X 是**纯原始计数**（`obs` 也未存 size factor），符合"不建归一化副本以省内存"的预设。
4. **float32 精度**：已验证本数据集安全（最大值 52,227），但此结论**对本数据集成立**，非普适保证。

### 7.2 诚实记录：审计**初版自身**有 3 个 bug（数据无问题）

审计第一次运行报了 2 个 FAIL。逐一查证后，**两处都是我的审计脚本写错，不是数据错**：

| 误报 | 根因 | 证据 |
|---|---|---|
| `A3` FAIL（max\|Δ\|=2，17/75 样本） | **float32 累加舍入**。样本和量级 4.4e7 > 2²⁴，float32 在此量级间距 ≥4，累加 80 万个数的舍入累积出 ±2 | 改用 float64 / int64 累加 → **max\|Δ\| = 0**。已在脚本中把 float32 的假偏差**如实记为 note**，说明该检查为何必须 float64 |
| `A6c` FAIL（23 名患者各有 3–5 个 stage） | **断言写反了**。本项目设计**就是同一患者多个分期**（同患者多病灶 = 配对设计本身，也正因此 `patient_id` 绝不可作 batch）。我却断言"患者内 stage 唯一" | 改为"每患者 stage_token 集合 == GEO 权威表" → **23/23 一致** |
| （自查发现）`A7a` 是**恒真式** | "逐样本计数之和 == n_obs" 恒成立，无检出力 | 替换为**行块连续性**检查 A7a' |
| （自查发现）`A6c` 第二次写错 | 在**逐细胞** obs 上 groupby → token 重复计数 | 加 `.drop_duplicates()` 先降到样本级 |

**结论**：数据无任何问题；这 3 个 bug 全部在审计侧，且已修正并留档。这也说明
**审计脚本本身也需要被质疑**——本报告不把"审计通过"当作免检金牌。

### 7.3 审计**仍不能**覆盖的残余风险（如实声明）

- **(行和, 非零数) 组合重复 252,677 / 648,945**。若两个细胞被互换且二者
  `(nCount, nFeature)` **完全相同**，则 A2b 与 A2c 会**双双照样通过**。该数字即此盲区的度量。
  实际兜底来自 A5（逐元素，3 样本）与 A7b（逐元素，12 块）——它们比对的是**真值**而非摘要。
- **A5 只覆盖 3/75 样本**（全量重抽取等价于重跑一次 21 分钟的构建）。
  如需**零盲区**，可对全部 75 样本做独立重抽取逐元素比对（约 21 分钟）。**未做，此处如实标缺。**
- 仍**不重新验证 M1 的 QC/双体判定本身**（见 §6.1）。
