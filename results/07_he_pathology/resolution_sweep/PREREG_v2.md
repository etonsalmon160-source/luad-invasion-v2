## 2. 决定设计的关键事实

**PLIP 的输入恒为 224×224。** ⇒ PLIP 实际看到的分辨率 = **裁框物理边长 / 224**。

| | 裁框 | 物理视野 | PLIP 有效分辨率 | 重采样 |
| :--- | ---: | ---: | ---: | :--- |
| 旧基线 L448 | 448 px @ 5.670 µm/px | 2540 µm | **11.34 µm/px** | ↓2.00（缩图） |
| — L320 | 320 px @ 5.670 µm/px | 1814 µm | **8.10 µm/px** | ↓1.43 |
| — L224 | 224 px @ 5.670 µm/px | 1270 µm | **5.670 µm/px** | **1:1，不重采样** |

⚠️ **旧基线把 hires 的 5.670 µm/px 白白扔掉一半** —— 448→224 的缩放本身就是损失。
`L224` 是**不重采样**的那一档，是本实验能达到的**最细**档。

### 2.1 🔴 必须登记的架构天花板（**决定了本实验的判读上限**）

PLIP = CLIP **ViT-B/32**。224 px 输入 → patch 32 px → **7×7 = 49 个 token**。
⇒ **一个 token 覆盖 32 个输入像素**：

| 臂 | 一个 token 覆盖的组织 |
| :--- | ---: |
| L448 | 32 × 11.34 = **363 µm** |
| L224 | 32 × 5.670 = **181 µm** |

🔴 **PLIP 在结构上无法表达比 ~180 µm/token 更细的信息**，无论源图多细。
⇒ **本实验的预期是「平坦」，而平坦的正确读法是「PLIP 用不上细节」，
不是「细节没用」。** 这条区分直接决定 H&E 线的退役措辞（§8）。

## 4. 臂

| 臂 | 源 | 裁框 | 物理视野 | PLIP 有效分辨率 |
| :--- | :--- | ---: | ---: | ---: |
| **L448P0** | hires | 448 px | 2540 µm | 11.34 µm/px |
| **L448P1** | hires | 448 px | 2540 µm | 11.34 µm/px |
| **L320P0** | hires | 320 px | 1814 µm | 8.10 µm/px |
| **L320P1** | hires | 320 px | 1814 µm | 8.10 µm/px |
| **L224P0** | hires | 224 px | 1270 µm | 5.670 µm/px |
| **L224P1** | hires | 224 px | 1270 µm | 5.670 µm/px |

★ **L448P0 = 管线锚**：它与旧基线（04/11）**同源、同裁框、同缩放、同提示词、同预处理**，
是在**抽样** spot 上的重跑。它存在的唯一目的是：证明本脚本的代码路径没坏。
**判据：L448P0 的切片级 rho 必须落在 0.60–0.78**（旧值 0.696）。落在区间外 ⇒ **硬停，查代码**。

× 两种预处理：

| 预处理 | 做法 |
| :--- | :--- |
| **P0** | 无。原始彩色裁框直接缩到 224 |
| **P1** | **背景压平**：裁框**转灰度**得亮度背景 `bg`，
三通道**各减同一个 `bg`**、再 +128、clip 到 [0,255] |
| | ⇒ 通道间差值（色相）**逐像素不变** ⇒ 不会踩 §1 的灰度坑 |

**判读核心**：
- **P0 阶梯（L448P0 → L320P0 → L224P0）**：细节加进来，判别力有没有变化？
- **P1 阶梯（同三档）**：剥掉大尺度明暗后，细尺度上**还剩不剩**判别力？
  （H&E 线此前被判定更像"组织密度/含气量读数"，P1 就是去混杂的那把刀）

**P1 的代价（必须登记）**：压平会**同时压掉组织密度**（那正是它要去的混杂）。
所以 P1 的分数天然不可能是"密度读数"，P0 才是与旧基线同族的量。

## 5. 抽样与过滤（**六臂统一**）

每张切片固定随机 **1000** 个 in-tissue spot（`numpy.default_rng(0)`，按 barcode 排序后抽）。

`tissue_frac` 与过滤**一律用 L448 裁框**（hires 448 px、2540 µm 视野）——
即**沿用旧基线 04/11 的过滤规则**，过滤是 **spot 的属性，不是臂的属性**
⇒ 六个臂拿到**逐字相同**的 spot 集，且 L448P0 与旧基线的可比性最强。

⚠️ **另记一列** `tissue_frac_224`（用 L224 裁框量），**只登记、不过滤**：
供事后检查「若改用更严的过滤，spot 集会怎么变」（法则 3.2：本列不得用于事后改过滤）。

被滤掉的 spot 数与 `clamped`（裁框触到图边被裁切）的比例**逐臂逐切片登记**。

## 8. 指标与判读

1. **切片级** mean score vs 分期 **Spearman rho**（n=56）
2. **扣掉密度后的偏相关**：控该臂自身的 `<img, d>`（d = 该臂嵌入空间的密度方向），
   置换 20,000 次给经验 p
3. **管线正确性锚点**：L448P0 的切片级 rho ∈ [0.60, 0.78]（§4）
4. **配对一致性**：同一 spot 上，各臂 **argmax 类目** 相对 L448P0 的**改变率**
   （六臂同 spot 集 ⇒ 可直接配对，不需要额外假设）
5. **判读表**

| 观察 | 读法 |
| :--- | :--- |
| `rho(L224P0)` 明显 > `rho(L448P0)` | 细节有用 ⇒ **H&E 线继续** |
| 两者**实质相同** | 在 5.67–11.34 µm/px 区间内细节无用 |
| `rho(*P1)` 明显 < `rho(*P0)` | 判别力主要来自**大尺度明暗**（密度）⇒ 与既有"密度读数"判定一致 |
| `rho(*P1)` 与 `rho(*P0)` 相当 | 剥掉密度后**另有**信号 ⇒ 值得重估 H&E 线 |

🔴 **平坦结果的措辞纪律（承接 §2.1）**：
必须写成「**在 5.670 µm/px 以上，PLIP 的判别力不随细节变化**」，
**不得**写成「细节对病理判别无用」—— 更细的档（≤1.9 µm/px）本 deposit **测不了**（§9）。

## 9. 🔴 登记时**已知**的局限

1. **测不到 5.670 µm/px 以下。** 唯一更细的彩色源不存在（§1）。
   第一版承诺的「细 6 倍」（1.890 µm/px）**不可实现** ——
   实测 `aligned_tissue_image.jpg` 只比 hires 细 **2.31 倍**（2.457 µm/px，视野比 1.30），
   **而且它是灰度的**，PLIP 读成空玻璃片 ⇒ 不可用。证据 `source_correspondence.png`。
2. **架构天花板 ~181 µm/token**（§2.1）⇒ 本实验**测的是 PLIP 能不能用细节，不是细节有没有用**。
3. **分辨率与视野共变**：裁得越小，每像素覆盖组织越少，但视野也越小
   （细胞数、组织异质性同时变）。两者在单一阶梯里无法解耦，**已登记**。
4. **同一张切片内 spot 不独立**（空间自相关）；切片级 n=56 是本实验的统计单位。
5. **Normal 只有 1 张切片**（P4_Normal）⇒ 队列级"肿瘤 vs 正常"对照 n=1。
6. **本图不是作者扫描的原始 WSI**（原始 WSI 全球不存在，见项目记忆）。
   本实验**不能**回答"用真原图会不会不一样"。
7. JPEG/PNG 有压缩损失；448→224 的缩小会引入混叠 —— 这正是 L448 相对 L224 的损失来源，
   是本实验**要测的东西**，不是要消除的噪声。
8. `aligned_fiducials.jpg` / `detected_tissue_image.jpg` 属 cytassist 帧，**含 fiducial 点阵**，
   本实验**不使用**。
