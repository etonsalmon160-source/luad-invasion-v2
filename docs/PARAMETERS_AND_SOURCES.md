## M1 · QC / doublets (**GSE308103 is snRNA**)

> 🔴 **2026-09-16 convention change (user decision "rebuild using the paper's QC")**: the primary convention was changed from this project's own
> **per-sample adaptive MAD** to the **source paper's fixed global threshold**. Reason: the paper's threshold is the native convention of these **same-platform, same-batch** samples,
> and its measured retained count (401,635) differs from our result after applying it (413,697) by **only 3.0%**;
> whereas the old adaptive-MAD convention kept **36% more nuclei** than the authoritative convention (648,945 vs 413,697), a systematic over-inclusiveness.
> The old convention is **not deleted**; it is demoted to a **sensitivity arm** (`results/02_expression/gse308103_counts.h5ad` retained).
