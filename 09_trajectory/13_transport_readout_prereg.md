## 0. 为什么要写这份

2026-09-26/27 实测结论（`realtime_kernel_structure.json` / `realtime_kernel_structure_all.json`）：

- RealTimeKernel 装出来的矩阵**永远是块上三角**，`strict_lower_nnz = 0`，在
  `self_transitions ∈ {diagonal, connectivities, all}` 三档下都成立。
- 整矩阵谱**逐位等于** IAC 那一块的谱（`1.0, 0.997833, 0.997233, 0.991893, …`），
  前四期对角块的特征值（≈0.5）排在后面，**运输数值一个都不进特征值**。
- 那个看着很干净的 0.5 vs 1.0「谱隙」是 `conn_weight = 0.5` 这个人造参数造出来的，
  改参数它就跟着跑。**用特征值间隙定宏观态，会把参数当成生物学。**
- 根源不是 cellrank 的实现缺陷：**「期别硬分区 + 只向前」必然块上三角**
  （`det(A−λI) = Π det(A_ii−λI)`），换 kernel、换参数都绕不开。

⇒ 结论：**谱机制这条路不要了。** 方向本来就是签字定死的（Normal→AAH→AIS→MIA→IAC），
谱方法存在的意义是「不知道方向时找慢模态」——我们没有这个问题。

⇒ 改为**直接用运输算**：方向已知 ⇒ 这是**打分问题，不是分解问题**。

## 2. 关键简化：进展读数只要矩阵-向量乘，不需要大矩阵

设第 i 期细胞的运输质量一路推到 IAC，得到一个分布 `Π_i(c, ·) ∈ R^{n4}`。
对任意 IAC 上的标量场 `u ∈ R^{n4}`，读数

    s(c) = Σ_d Π_i(c, d) · u(d)

**不需要构造 `Π_i`。** 令 `w4 = u`，然后**逐期回代**：

    w3 = T_34 · w4        (长 n3)
    w2 = T_23 · w3        (长 n2)
    w1 = T_12 · w2        (长 n1)
    w0 = T_01 · w1        (长 n0)

则**第 i 期的细胞 c 的读数就是 `w_i(c)`**（`i=4` 时 `w4 = u`）。

- 成本：4 次稠密矩阵-向量乘（读 ~9 GB）⇒ **秒级到分钟级**。
- 内存：**不需要任何大矩阵**（只存向量 + 每次读进一个耦合）。
- 这是本预注册能便宜做出来的根本原因。

若要做**分布形状**（双峰？见 §4.3）才需要真的构造 `Π_i`；最宽的一步
`Π_0 = T_01·T_12·T_23·T_34` 是 32251 × 56134 float64 = **14.5 GB**，
逐期从右往左乘、峰值约 18 GB ⇒ 可行，但列为**次要读数**。

### 2.1 行和 ≠ 1 怎么办（**这是需要签字的分叉**）

运输不守恒，所以「均值」有两种算法：

- **主口径：先逐行归一化**，`T̃[i,:] = T[i,:] / T[i,:].sum()`。⇒ `w` 是**纯分布均值**，
  生长率被剔掉。理由：这一步只做正缩放，不改方向信息，让读数可解释为「后代在哪里」。
- **敏感性口径：不归一化（原始 `T`）**。⇒ 生长率会进入读数，`w` 会偏向运输质量大的
  后代。**必须两档都报**；两档结论不一致 ⇒ 登记为「读数被生长率主导」，降级。

⚠️ 登记：归一化会丢掉 WOT 的生长率信号（这本身就是 WOT 的产出之一）。
本预注册**不用**生长率做任何结论，只用它做**敏感性对照**。

## 4. 四个检验

### 检验 1：对照零模型的地板（答 Q1）

对每个相邻对 (i, i+1)：

1. **真运输预测**：`x̂(d, g) = Σ_c T[c,d] · x_i(c, g) / Σ_c T[c,d]`（按目标细胞 d 归一）。
2. **零模型预测**：把 `T` 换成**独立耦合**（`T_null[c,d] ∝ w_c · v_d`，行/列边际的
   外积，即「运输完全无视表达」），同样算 `x̂_null`。
3. 比较两者与**实测** `x_{i+1}` 的吻合度：对每个目标细胞算与实测的 Pearson 相关
   （跨基因），报中位数；同时对每个基因算跨细胞的相关，报中位数。
4. **判定**：真运输**必须**明显优于零模型。若差值 ≈ 0 ⇒ **运输没有表达内容，路线死，
   后续检验不再解读**。

⚠️ 这一步是**地板，不是发现**：WOT 的熵正则目标本身就是对齐分布，所以真运输大概率
好看。**好看的数值不构成任何生物学结论。**

### 检验 2：读数阶梯（答 Q2，主检验）

预注册**四个坐标**，**全部提前写死**：

| 档 | `u` 的定义 | 角色 |
|---|---|---|
| **U1** | 全 133,384 细胞 harmony 嵌入（50 维）的 **DC1**（扩散分量 1，kNN 图 k=20 建在 harmony 上）；符号按「与期别序号正相关」定 | **主**（真实轨迹坐标） |
| **U2** | `nFeature`（检出基因数） | **阴性对照**（深度） |
| **U3** | `pct_mt` | **阴性对照**（线粒体比例） |
| **U4** | 固定种子的随机场 | **阴性对照**（纯噪声地板） |

对每一档算 `s(c)`（§2 的回代），然后量**同期别内部的离散度**：

- **SD(s | stage)**，与「把 `u` 在同一期内随机打乱重算」的置换零分布比（1000 次）。
- **同期同患者的患者间一致性**：`s` 的患者效应 vs 残差（方差分解，报 η²）。
- **单调性**：`median(s | stage)` 是否沿 Normal→IAC 单调（这是**必要**条件）。

**判定规则（预先写死）**：

- **PASS**：U1 的期内离散度显著高于置换零分布（`p < 0.01`），**且** `η²_患者 < 0.5`，
  **且** `median(s | stage)` 单调，**且** U1 的离散度**严格大于** U2/U3/U4 三档。
- **FAIL（路线死）**：U1 与 U2（深度）**不可区分** ⇒ 读数只是深度搬运。
- **FAIL（路线死）**：U1 的离散度不超过 U4（随机场）⇒ 运输没有把任何连贯的东西推过去。
- **降级（不判死）**：`η²_患者 ≥ 0.5` ⇒ 读数主要反映患者差异，按患者分层重报。

### 检验 3：基因趋势（答 Q3）

对每个基因 g，量**运输加权的期望表达沿轴的变化**：

    Δ_i(g) = mean_d( x̂_i→i+1(d, g) ) − mean_c( x_i(c, g) )

（即「推过去的下一代表达画像」减「当前画像」，逐期算。）

- **候选基因** = 四步 `Δ` **同号**、且 |Δ| 超过该基因跨患者 bootstrap 的 95% 分位。
- **必查**：留一患者（23 次）后是否仍入选；只有 1–2 个患者驱动的**一律剔除**。
- **命名**：只能写「沿期别轴变化的**候选**基因」。**不得**写 driver / causal / 驱动
  （铁律 6 精神）；**不得**读成恶性判别（铁律 2；单细胞 CNV 已于 2026-09-24 退场，
  全项目**不存在**逐细胞恶性标签）。

### 检验 4：患者分层（贯穿 2、3）

所有结论必须按 23 患者分层重报：

- 每一期里，贡献最多的患者占比是多少（`top_patient_frac` 的同类指标）；
- 留一患者后结论是否翻转；
- AAH（8 患者）和 **MIA（4 患者）** 的结论单独标注为**弱证据**。
