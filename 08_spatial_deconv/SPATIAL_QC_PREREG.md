## 0. 为什么必须补这一份

**空转 spot 级质控在本项目不存在。** 三处可以印证：

| 证据 | 内容 |
| :--- | :--- |
| `01_qc/` 与 `results/01_qc/` | **全部是 GSE308103 snRNA**（M1 双体过滤、逐样本自适应 MAD），没有一行碰 Visium |
| `docs/AUDIT_M0_M1.md` §3⑦ | 已如实写「**空间 spot QC 未做**」「GSE307534 的 spot 级 QC 属空间前处理，尚未执行」 |
| `PLAN_AND_CHECKPOINTS.md` §2.0 | 13 行执行表（M1 / GP0 / GP4a–c / GP5 / GP6 / GP8a / GP2 / GP8b / GP3 / GP7 / GP9 / M4）**没有一行是空转** |

而 M5（RCTD）必须吃 spot。**这就是问题所在**：

`spacexr::create.RCTD()` 自带 `UMI_min = 100`、`counts_MIN = 10`，**它会丢掉 spot**。
如果 "哪些 spot 算数" 这件事只由这两个包默认值决定，那么：

- 我们**事后分不清**「这个 spot 是被我们的 QC 排除的」还是「被 RCTD 拒绝的」；
- 某个切片 spot 掉得多时，我们会不知道**该查 QC 还是该查 RCTD**；
- 更糟：调这两个默认值就能改变 spot 集合 ⇒ **等于事后择果**（法则 3.2 禁止）。

⇒ **两个剔除层必须分开：先由本模块独立冻结 spot 掩码，RCTD 的第二次剔除单独计数、单独上报。**

## 2. 本模块**做**什么、**不**做什么

**做**（产出物只有两样）：

1. **逐 spot 的可测性指标**：总 UMI、检出基因数、线粒体基因占比、是否组织内。
2. **一份冻结的 spot 掩码**（`spot_mask.tsv.gz`：`slide, barcode, in_tissue, total_umi, n_genes, pct_mt, pass`）＋ 逐切片汇总。

**不做**（硬边界）：

- ❌ 不判恶性（那是 GP2 / CNV 的事，见 `RCTD_PREREG.md` §1.1 R2 边界）
- ❌ 不给细胞类型、不给权重（那是 RCTD）
- ❌ 不做 CNV、不做空间邻域统计（那是 M2 / M6）
- ❌ **不替换 RCTD 自己的 `UMI_min` / `counts_MIN`**——那两个仍然生效，是**第二层**剔除（§4 SP4）

**签字记录（见 §7 第 1、2 项）**：

| 项 | 用户裁定 | 原话 |
| :--- | :--- | :--- |
| 三个阈值 | 照原文 500 / 200 / 0.15 | 「照原文 500 / 200 / 0.15」 |

⚠️ **单位**：`MAX_MT_FRAC = 0.15` 是**比例**；QC 表里的 `pct_mt` 是**百分数**（0–100）。
代码里显式写 `mt_pct_max = 100.0 * SIGNED['MAX_MT_FRAC']` 并把换算打印出来 ——
**不做心算**（这类单位混用是静默错一个数量级的经典来源）。

原文那句话用的是 **`and`**，字面读＝「三个同时不达标才剔」。实测这个读法没有生物学意义
（一个 spot 只要有 50 UMI、30 基因但 MT 只有 2% 就会**幸存**）。本节两种读法都算了数
（§3.2），**签字取 OR**（唯一有生物学意义的读法；4.97% 就是它的值）。

### 3.1 为什么这三个**必须看了图才能定**（不能照抄 snRNA）

`PLAN_AND_CHECKPOINTS.md` GP0 行已经有一套 snRNA 的 QC 口径：`nFeature≥500 & nCount≥1000 & pct_mt≤20`。
**它不能照搬到空转**，理由不是"惯例不同"，是**物理量不同**：

| | snRNA（GP0） | Visium spot |
| :--- | :--- | :--- |
| 一个观测单位是什么 | **1 个细胞核** | **55 µm 见方里的一堆细胞**（含细胞外 mRNA） |
| 组织内还有 | — | **环境 RNA**（P24 已确认存在，见 `project_p24_ambient_confirmed_pending_disposition`） |
| 线粒体占比的含义 | 细胞破损 | 破损 **＋** 该 spot 落在什么组织（心肌/肌肉区天然高） |

⇒ 同一个数值（比如 MT=20%）在两个模态里**不是同一件事**。
定阈值必须看**本队列 639,816 个 spot 的实际分布**，并且**与 snRNA 的旧口径并排对照**看差多少。

👉 **需要出的图**（放项目目录，不放 `/tmp`）：逐切片的总 UMI / 检出基因数 / MT 占比分布（小提琴 ＋ 累积曲线），
叠加 snRNA 的 `nCount` / `nFeature` / `pct_mt` 同指标分布作参照。

🔴 **在这些图看过、三个常数签过字之前，本模块不跑**（口径法则：口径未定不许启动计算）。

### 3.2 2026-09-24 实测：原文阈值套在本队列上是什么结果

`--figures-only` 已跑完 56 张 / 639,816 spot（只读，未冻结任何掩码）。三张图在
`results/08_spatial_deconv/`：`spatial_qc_thresholds.png`、`spatial_qc_droprule.png`、
`spatial_qc_sensitivity.png`。

**（a）两个读法，没有一个复现原文的 1.05%：**

| 读法 | 剔掉 | 占比 | vs 原文 1.05% |
| :--- | ---: | ---: | :--- |
| **OR**（任一不达标即剔，＝ Seurat `subset` 常规写法） | 31,773 | **4.97%** | 4.7 倍 |
| **AND**（原文 `and` 的字面读法） | 99 | **0.01%** | 1/100 |

⇒ **原文自报的 1.05% 不能用来反推那句 `and` 是什么意思** —— 两个读法都够不着。
OR 是唯一有生物学意义的读法（AND 会放过 50 UMI / 30 基因的 spot）。

**（b）三个判据里，只有 nUMI 在起作用：**

| 判据 | 不达标的 spot | 占比 |
| :--- | ---: | ---: |
| `nUMI < 500` | 31,657 | 4.95% |
| `nFeature < 200` | 9,562 | 1.49% |
| `pct_mt > 15%` | **225** | **0.04%** |

⇒ **MT 阈值在本队列上几乎不做事**（中位 MT = 1.03%，逐切片中位最高约 4%）。
三个常数里 `MAX_MT_FRAC` 取什么值，对结果基本没有影响 —— 但**仍然要签字**，
因为它是"我们没有放宽原文标准"的凭证。

**（c）4.97% vs 1.05% 的差距，根因是逐切片深度不均，不是规则读错：**

- 逐切片剔除率：中位 **2.60%**，最低 0.02%，最高 **29.56%**
- 剔除率与该切片测序深度的秩相关 **Spearman r = 0.83**（`spatial_qc_sensitivity.png` 右图）
- 最深的 6 张（P8_LUAD 29.6% / P16_AIS 24.9% / P17_AIS 18.2% / P8_AIS 16.4% /
  P4_AAH-1 15.1% / P9_AIS 15.1%）中位 nUMI 只有 861–1,751；去掉这 6 张就是 3.10%
- **要凑到 1.05%，得把 nUMI 阈值降到 173** —— 那会放过 200 UMI / 100 基因的 spot，不可接受

⇒ **处置（按 `feedback_gate_failure_registered_as_defect.md`）：
保留原文参数，不调参凑数，把差距登记为缺陷。**

**（d）深度对比 —— 原先"我们比原文浅"的担心可以撤：**

| | 中位 genes/spot |
| :--- | ---: |
| 我们（56 张合并） | 2,994 |
| 我们（逐切片中位再取中位） | **3,149** |
| 原文自报 | **≈ 3,400** |
| 我们逐切片范围 | 734 – 8,210 |

⇒ 整队列深度与原文基本一致；之前的 2,054 是 `P4_Normal` 单张（属低端），不是全体。

**（e）仍然缺的一层（登记为局限，不补）：**
原文的 1.05% 是**在病理学家剔除 "Space" / "Foreign body" / "Tissue artifacts" 之后**才统计的。
那三类 spot 通常正是低计数 spot ⇒ 原文的分母已经先被清过一轮，这能部分解释差距方向。
我们无逐 spot 病理注释 ⇒ **这一层永久缺失**，不冒充、不近似。
