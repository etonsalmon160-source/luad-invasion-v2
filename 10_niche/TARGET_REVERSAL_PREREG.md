## §4 口径 —— **权威出处的调研结果**（2026-10-03）

**来源：Subramanian A, et al. "A Next Generation Connectivity Map: L1000 Platform and the First
1,000,000 Profiles." *Cell* 2017**（PMC5990023）。以下**逐字/逐式引自该文**，不是我们的发明。

### §4.0 三个关键定义（原文）

1. **查询签名 = 带符号的基因集**：
   > 「Each gene in the query carries a **sign** indicating whether it is up-regulated or down-regulated.」
   ⇒ 查询是 `q_up` / `q_down` 两个集合，**不是**一个排序列表。
2. **WTCS（加权连通性分数）**：
   > 「a non-parametric similarity measure based on the **weighted Kolmogorov-Smirnov enrichment statistic (ES)**」
   即 GSEA 式加权 KS 统计量。
3. **NCS（归一化连通性分数）** —— **注意归一化用的是"细胞系×扰动类型的带符号均值"，不是分位数**：
   > `NCS_{c,t} = w_{c,t} / μ⁺_{c,t}` (若 `sgn(w)>0`)，否则 `w_{c,t} / μ⁻_{c,t}`
   > 其中 μ⁺/μ⁻ 是**该细胞系×扰动类型内 WTCS 的带符号均值**。
4. **τ（Tau，−100…+100）** —— 对**参照查询库 Q_ref** 的标准化：
   > `τ_{q,r} = sgn(ncs_{q,r}) · (100/N) · Σ_{i=1..N} [ |ncs_{i,r}| < |ncs_{q,r}| ]`
   > 「Our standard practice is that **Q_ref** be comprised of queries obtained from exemplar signatures of
   > **Touchstone** perturbagens that match the cell line and perturbation type of signature r.」

### §4.1 🔴 一条**更正**：旧工程的 `τ ≤ −90` **不是误用**

原文给出的 τ 阈值惯例（逐字）：

| 阈值 | 原文语境 |
|---|---|
| **τ ≥ 90** | 「a τ of 90 indicates that only 10% of reference perturbations showed stronger connectivity to the query」——**标准工作阈值** |
| **τ ≥ 95** | 「44 such **dually connected** compounds were found (τ>=95, selectivity >=0...)」 |
| **τ ≥ 98** | 「111 Discovery compounds had **strong and selective** connections (τ >= 98)」 |

⇒ **逆转方向就是 `τ ≤ −90`**，这是**标准做法**。
旧工程的错**不在阈值**，而在**硬编码 + 无真实数据**（`cmap_lincs_reversal_perturbagens.FABRICATED.csv`）。此点更正。

### §5.2 查询签名 `q_up` / `q_down` 的构造

### §5.3 WTCS（加权连通性分数）—— 逐步算法

参照谱 `r` = 某扰动在该细胞系下的差异谱，**按值降序**排成 rank list（长度 N）。

对基因集 `S`（|S| = N_S），**加权 Kolmogorov–Smirnov 统计量**（Subramanian 2005 GSEA 式；CMap 2017 原文：
「based on the **weighted Kolmogorov-Smirnov enrichment statistic (ES)**」）：

```
R_j = |r_j|^p                                   # 命中基因的权重
N_R = Σ_{j∈S} R_j
running:  在 j 处，若 j∈S： + R_j / N_R
                    否则：   − 1 / (N − N_S)
ES_S = 偏离 0 最大的有符号值（正/负取绝对值最大者，保留符号）
```
- **权重指数 p = 1**（GSEA 默认值；写在案）

**双向合成**（CMap 2017 逐字）：
```
WTCS = (ES_up − ES_down) / 2    若 sign(ES_up) ≠ sign(ES_down)
WTCS = 0                        否则
```
- 单臂情形（只有 up 或只有 down）⇒ 该臂 ES 直接作为 WTCS（本项目**恒为双臂**，故不触发）

### §5.4 NCS（归一化）——**注意归一化对象**

CMap 2017 原文：
```
NCS_{c,t} = w_{c,t} / μ⁺_{c,t}   若 sgn(w) > 0
NCS_{c,t} = w_{c,t} / μ⁻_{c,t}   否则
```
其中 **μ⁺ / μ⁻ = 在「细胞系 × 扰动类型」分组内、WTCS 的带符号均值**。

- **L1**：分组键 = `cell_id` × `pert_type`（取自 `sig_info`）
- **L2**：**没有"细胞系"**这一层 ⇒ 分组键 = `dataset`（15 类）；其余同 L1
- ⚠️ **易混点**：`NCS = w/μ` 才是归一化；CMap 里另有 `Q_hi/Q_lo` 的**跨细胞系聚合**步骤（maximum quantile），
  **那是聚合不是归一化**，本轮**不做**（我们不跨细胞系聚合）

### §5.5 τ（Tau）—— 含**降级说明**

CMap 2017 原文：
```
τ_{q,r} = sgn(NCS_{q,r}) · (100/N) · Σ_{i=1..N} [ |NCS_{i,r}| < |NCS_{q,r}| ]
```
`Q_ref` = 参照查询集：原文「queries obtained from exemplar signatures of **Touchstone** perturbagens
that **match the cell line and perturbation type** of signature r」。

✅ **2026-10-04 更正：Q_ref 拿得到，降级不必要了。**

`is_touchstone` **确实不在 GEO 的元数据里**（已逐个查证：GSE70138 `sig_info`、GSE92742 `inst_info`/`sig_info` 均无该列）。
**但它在 Bioconductor `signatureSearch`（Bioc 3.16 / 1.12.0）随包分发的数据对象里**：

```
signatureSearch/data/lincs_pert_info.rda   →  对象 lincs_pert_info
「LINCS 2017 Perturbation Information」8140 行 × 40 列
含列 pert_id / pert_iname / pert_type / **is_touchstone** / MOA / mechanism_of_action /
     max_phase / DrugBank_ID / chembl_id / selectivity_comment …
is_touchstone:  0 → 5929   |   1 → 2211
```
**获取方式**：直接下 `signatureSearch_1.12.0.tar.gz`（5.08 MB）解包即可，**不装包、不注册**。

**实测可接性**（与 GSE70138 `sig_info` 按 `pert_id` 连接）：
- `pert_id` 命中率 **48.3%**

⇒ **Q_ref 按 CMap 2017 原义构造**（「match the cell line and perturbation type of signature r」）。

🔴 **保留的限定（必须随结果同页）**：
1. `pert_id` 只有 **48.3%** 能判 touchstone ⇒ **约一半签名无法归类**，τ 对这些签名的参照仍是"同组 touchstone 集"（若该组无 touchstone，则退回随机查询降级版，**逐条标注**）。

### §5.14 ✅ Q_ref 的 `exemplar` 口径（2026-10-04 定稿，用户：「取一个代表性的参考原算法口径，这个一定也要明确和严谨」）
