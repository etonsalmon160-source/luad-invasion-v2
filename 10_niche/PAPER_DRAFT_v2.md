## Abstract

我们构建了一套**同一患者配对**的肺腺癌病程队列（23 例；snRNA **413,697 核**；Visium **56 张切片**），
覆盖 Normal → AAH → AIS → MIA → IAC，并在此之上系统评估了**五类**分析：病理图像、
空间解卷积、发育轨迹、空间生态位、扰动逆向。

**贯穿全部五类的是一个同一现象**：在 55 µm Visium spot 上，**测序深度与组织密度耦联**，
使得"最像疾病"的信号恰恰是深度最强的信号。我们给出三件可复用的方法学工具：
（i）**深度–签名稳定性标定曲线**（七域，秩相关 **−0.893**，两种独立估计量一致）；
（ii）**与官方逐位一致的连通性标尺**（对 `signatureSearch` 1.12.0：WTCS 最大差 **6.6e-14**、符号 2000/2000）；
（iii）**阳性对照校准的扰动管道**（逐条复现 SCMG 官方教程：TBXT 第 1、SNAI1 第 5、EOMES 第 6，共 2,889）。

方法学确立后，我们把查询换成**患者内配对的全局疾病轴**并施加**基于 TCGA-LUAD 生存的预后质控**
（483 例，逐基因调整 Cox；剔除 46%），三种逆转评分并排。
**CMap 类与相关类的 top-500 仅重叠 ~1/3，两种相关评分重叠 47/50** —— 与文献对 CMap"丢弃扰动值"的批评一致。
相关评分给出 **34 个跨方法一致的化合物**，机制集中于 **PI3K/mTOR**，
在**四次患者劈半**（ρ **0.962** vs 零模型 −0.155）与**跨模态**（单细胞 vs 空转 **0.735**）下稳定复现。

**我们不主张已发现治疗靶点**：候选全部来自癌细胞系上下文、未在肺成纤维验证、且无实验验证。

## 13. 贯穿性发现：深度–密度耦联

**把同一个深度配平检验铺到全部七个域**（七域自带七个深度倍数，1.00×–7.95×）：

| 域 | 深度倍数 | 配平后 up 存活 |
|---|---|---|
| D6 血管壁平滑肌 | 1.43× | 59% |
| D4 肺泡壁 | 1.00× | 52% |
| D2 支血管周 | 1.26× | 47% |
| D1 气道上皮 | 2.12× | 33% |
| D7 淋巴聚集 | 2.58× | 29% |
| D5 AT2 | 3.38× | 14% |
| **D3 ECM/间质** | **7.95×** | **11%** |

**秩相关 −0.893**；两种独立估计量（十分位配平 / 逐基因回归残差）**几乎逐位一致**。

**⇒ 深度不是纯技术混杂，它是组织/细胞密度的代理**：
```
组织密度（生物学）
  ├→ 测序深度（counts 多）
  └→ 细胞组成（肿瘤密、间质少）→ 聚类 → D3 域
```
**把深度当协变量剔除 = 把中介当混杂剔了（over-adjustment）。"深"很可能就是"肿瘤密实"这件事本身。**

**这与 H&E 那条线独立对上**：`corr(neoplastic, 组织占比) = 0.825` —— 同一个耦合，两种完全不同的读数。

# 4. 讨论

## 4.1 一个统一解释

**五条独立路线（H&E、空间 CNV、生态位、发育谱、扰动逆向）指向同一个原因**：
在 55 µm Visium spot 上，**测序深度与组织密度耦联**。

两条完全不同的读数独立对上：
- PLIP 的 `corr(neoplastic, 组织占比)` = **0.825**
- 七域深度–签名曲线 **−0.893**

**后果**：最"像疾病"的签名恰是深度最强的签名；剔除深度会连着**真生物学（肿瘤密实）一起剔掉**；
因此"深度配平后消失"的信号**既可以是伪影、也可以是被一并剔除的密度生物学 —— 现有数据分不开**。

## 4.2 方法学的可复用产出

1. **深度–签名稳定性标定曲线**（−0.893）
2. **与官方逐位一致的连通性标尺**（6.6e-14）
3. **阳性对照协议** —— 扰动预测类分析必须先过此门
4. **配对队列入侵的完整 QC 与缺陷登记范式**（含三个静默出错的修复）

## 4.3 PI3K/mTOR 候选：意义与限度

**强度**来自三重独立收敛。**限度**：
- 全部来自**癌细胞系上下文**，**未在肺成纤维验证**
- **无实验验证**
- 该轴是**组分加权的组织状态**，含细胞组成效应，不是纯细胞内在程序
- CLUE 的官方 FDR 层已随服务消失；我们的显著性靠**置换与稳定性**，**不是官方 FDR**

**⇒ 只称"候选化合物"，不称"药物"。**

## 4.4 与原文的关系

原文早期促炎生态位富集，本队列**方向相反（未复现）**。三条不可比边界已登记。
**不复现不等价于原文有误。**
