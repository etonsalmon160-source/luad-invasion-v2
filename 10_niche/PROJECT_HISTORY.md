# 第一阶段 · 单细胞基础（09-12 → 09-22）

## M0/M1：输入冻结与 QC（PR #1, #2）

**PR #1 冻结了三个公共 scRNA 队列，PR #2 立刻收窄为两个配对数据集**：

- **GSE308103**（snRNA）+ **GSE307534**（Visium）—— 唯一**同一批患者**的两个模态。
- 三个外部队列移出范围（存档未删）。

**为什么必须重做输入层**：前一版工程**污染过分期标签**（TD9 误标 AAH、`nLN` 当 LNM、
脑转移/胸膜积液并入 IAC）、并用启发式双体代理。
⇒ **M0 用 GEO 权威元数据重建，未知分期 token 一律 `raise`，绝不静默默认。**

🔴 **一处关键更正**：`patient_id` 取自 **GEO 的 `patient id` 字段**，**不是**样本名前缀。
`LUNG_N06`(P0006)、`EBUS_06`(P1006)、`LN_06`(P2006)、`NS_06`(P3006) 是**四个不同患者**。

**结果**：94 样本 / 25 患者 / **23 例双模态配对**；M1：798,100 核 → 767,839 pass（96.21%），
双体 118,894（15.48%）。

**核专用阈值**：逐样本 MAD（`nmads=3`）+ `pct_mt<5`，**不照搬 scRNA**（后者砍掉约 30% 核）。

**两项独立双体验证**：① **75/75 样本**双体 nCount 比中位 **2.39**；
② 跨谱系共表达（EPCAM+/PTPRC+）在 doublet 中为 singlet 的 **7.2×**。

### 🔴 三个会**静默出错**的缺陷（PR #2 修的）

| # | 症状 | 根因 |
|---|---|---|
| 1 | `cell_barcode` 全为 `"0\|<样本>"` | `fread` **autostart 跳过条码行** ⇒ 标识失效、丢失 SAMD11 |
| 2 | 修 1 后又被多丢一行 | `dt[-1,-1]` 重复丢行 |
| 3 | `P7_LUAD` 双体率 **0** | scDblFinder 默认 **xgb 分类器塌缩**（非生物学）⇒ 改 `score="weighted"` 得 11.69%，主脚本加自动 fallback |

- ⇒ **被抹掉的部分数学上不可归因。下游任何分期相关结论不得声称已排除批次混淆。**

|---|---|---|

**原文核对**：逐词检索 PMC 全文 ⇒ `ambient`/`soup`/`SoupX`/`CellBender`/`DecontX`/`EmptyDrops`、

# 贯穿性发现（本项目最硬的结论）

## 深度–密度耦联，有**两条完全独立的读数**

| 读数 | 数字 | 来自 |
|---|---|---|
| **PLIP 图像**（H&E 切片） | `corr(neoplastic, 组织占比)` = **0.825** | PR #11 |
| **Visium 表达**（七域曲线） | 秩相关 **−0.893** | PR #18 |

**两条线用的是完全不同的数据（组织切片图像 vs 测序计数），却指向同一个耦合。**

七域曲线（七域自带七个深度倍数）：

| 域 | 深度倍数 | 配平后 up 存活 |
|---|---|---|
| D6 血管壁平滑肌 | 1.43× | 59% |
| D4 肺泡壁 | 1.00× | 52% |
| D2 支血管周 | 1.26× | 47% |
| D1 气道上皮 | 2.12× | 33% |
| D7 淋巴聚集 | 2.58× | 29% |
| D5 AT2 | 3.38× | 14% |
| **D3 ECM/间质** | **7.95×** | **11%** |

**因果结构**：
```
组织密度（生物学）
  ├→ 测序深度（counts 多）
  └→ 细胞组成（肿瘤密、间质少）→ 聚类 → D3 域
```
**把深度当协变量剔除 = 把中介当混杂剔了（over-adjustment）。"深"很可能就是"肿瘤密实"这件事本身。**

**⇒ 三条独立线索互相印证**：RCTD 深度守卫的真检验（argmax 移动 9.93%）、PLIP 的 0.825、七域的 −0.893。
